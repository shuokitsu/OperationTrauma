### 1.1 操作と結果の早見表

- **この表は3章（各機器の仕様）の要約。内容が食い違った場合は3章を正とする。**

| 機器 | 操作方法 | 判定方法 | 成功 | 失敗 | 無効 | 空振り |
|---|---|---|---|---|---|---|
| ヒールゼリー | 押してなぞる（塗る） | ヒットエリアをすべて覆ったか | 覆った | なし | 覆いきれない、手順違い、ストック0 | 回復（押した瞬間に1、以後2秒ごとに1、1回最大10） |
| ドレーン | 押し続ける | 押している位置がヒットエリア内か | 吸い切った | なし | 吸う物が無い病巣の上 | 何も起きない |
| ピンセット | 掴んでドラッグし、運び先で離す | 掴む位置、離した位置 | 運び先で離した | 運び先以外で離した | 掴めない物（手順違いを含む） | 何も起きない |
| メス | 1回でなぞる（切る） | 通過点（順番どおり）と猶予幅 | 全通過点を順に通った | 猶予幅を外れた、線状で端以外から切り始めた、通過点を飛ばした、手順違い | 途中で離した | ダメージ＋小さな切り傷の発生 |
| 縫合針 | 1回のスワイプで、線をまたぐようにジグザグに縫う | 線をまたいだ回数 | 離した時点で、通過点の数以上またいでいた | 猶予幅の外に出た | 離した時点で、またいだ回数が通過点の数に足りない | ダメージ（縫う段階ではない病巣の上も含む） |
| 注射 | 押している間注入 | 薬の種類による | 注入した | 薬による（手順違い）。限度量を超えたらゲームオーバー | ゲージ0 | 回復剤・麻酔：なし（どこでも効く）。特定の病巣用：ダメージ、注入しない（対象外の病巣の上も含む） |

## 2. 共通ルール

### 2.1 操作の結果の分類

- 操作の結果は、成功・失敗・無効・空振りの4つに分ける（[07_data_format.md](07_data_format.md) 2.2）。値の置き場所もそこに従う（空振り → 医療機器データ、成功 → 病巣データ、失敗 → 病巣データ（無ければ医療機器データの既定値）、無効 → 値なし）。
- **空振りになる範囲**：手術エリアの中で、病巣のヒットエリアに重ならない場所を操作したとき。手術エリアの外（医療機器の列など）での操作は何も起きない。
- **その機器にとって対象にならない病巣の上での操作は、空振りとして扱う場合がある**（縫合針を縫う段階ではない病巣に使ったとき、特定の病巣用の薬を対象外の病巣に打ったとき）。その病巣は、その機器にとっては「無い」のと同じと考える。値は空振りと同じく医療機器データに持つ。機器ごとの扱いは 2.2 の表。
  - **補足**：こうすることで「無効＝何も起きない（ダメージも無い）」のルールを崩さずに、ダメージを与えられる。

#### 1回の操作の結果の決め方（縫合針・注射の空振りは決定。メスの部分は【仮案・未確認】、`TBD-05-15`）

メス・縫合針のように軌跡が長い操作でも、結果が実装者ごとに割れないよう、次の共通ルールを置く（空振りのダメージを与える時点のうち、縫合針は決定。ほかは仮案）。

1. **1回の操作（押してから離すまで）の結果は1つ**。成功・失敗・無効・空振りのどれか（ヒールゼリーだけは、複数の病巣を一度に塗れるため、病巣ごとに成功・無効を判定する）。
2. **分類は押した位置で決める**。押した位置が、病巣の判定領域（ヒットエリア、または通過点を結んだ線から猶予幅以内）の内側なら「その病巣への操作」、外側なら空振り。
3. 押した後に軌跡が別の病巣の上を通っても、分類は変えない。
4. 空振りのダメージを与える時点と回数：**1回の操作につき1回**。縫合針と特定の病巣用の注射は**押した瞬間**（決定。縫合針は試作 v02 の P37 への回答、2026-10-02）。メスは軌跡が「切った」とみなす最短の長さ（3.4）に達した時点（【仮案・未確認】）。

### 2.2 手順違い

手順違いの結果は機器ごとに決める。

| 機器 | 手順違いの結果 | 対象外の病巣の上での扱い |
|---|---|---|
| ヒールゼリー、ドレーン、ピンセット | 無効（ダメージなし） | 無効（何も起きない） |
| メス | 失敗（ダメージ） | 失敗（【仮案・未確認】メスの手順を持たない病巣の上でも、手順違いとして失敗。`TBD-05-23`） |
| 縫合針 | 空振りと同じ扱い（ダメージ 1）。縫う段階ではない病巣は、縫合針にとって関係ない病巣と同じと考える（例：血溜まりが残っている裂傷を縫った） | 空振り（ダメージ 1） |
| 注射 | 薬ごとに決める（ダメージになる薬もある） | 特定の病巣用の薬：空振り（ダメージ 1、注入しない）。回復剤・麻酔：対象外という概念が無い（どこでも効く） |

- **補足**：塗る・吸うだけで患者が傷つくのは不自然なので、体を傷つける機器（メス・縫合針）以外は無効にする。試しに触っただけでダメージを受けると、手順を覚えるまでが厳しくなる。
- 例（注射）：特定の病巣用の薬を、対象の病巣の**別の段階**に打ったときは「手順違い」（薬ごとに無効または失敗）、**別の病巣**に打ったときは空振り（ダメージ 1）。

#### 「省略できる段階」と手順違い（【仮案・未確認】、`TBD-05-23`）

- 病巣の手順に「省略できる段階」がある場合（例：切開の消毒＝ヒールゼリー）、その次の段階の機器（メス）を先に使うことは**手順違いではなく「省略」**として扱う。省略したときのダメージは病巣データが持ち、**次の段階が成功した時点で**与える（例：メスで成功してもダメージ。[06_lesions.md](06_lesions.md) 3.5）。
- 省略できない段階を飛ばして次の機器を使った場合が、上の表の手順違い。
- 省略のダメージは、失敗・空振りとは別の扱い。**ミスの数には数えない。省略したことをプレイヤーに伝える表示も出さない**（決定。試作 v02 の P43 への回答、2026-10-02）。治療の評価（Cool／Good／Fine／Bad）の条件に「手順の省略をしない」を入れる案があるが、評価は再検討中（[03_game_rules.md](03_game_rules.md) 5.1、`TBD-03-16`）。

### 2.3 ヒットエリア

- **ヒットエリアは病巣側が持つ判定の範囲**（病巣の判定データ）のこと。医療機器側にはヒットエリアを持たない（[04_surgery_area.md](04_surgery_area.md) 2章）。
- 機器ごとの判定のしかた：

| 機器 | 判定 |
|---|---|
| ドレーン、ピンセット（掴む）、注射（特定の病巣用） | 操作した位置がヒットエリア内なら OK |
| ヒールゼリー | ヒットエリアを**すべて**塗って覆えば OK |
| メス | 通過点で判定する（3.4） |
| 縫合針 | 通過点を繋いだ線をまたいだ回数で判定する（離した時点で、通過点の数以上なら成功。3.5） |

### 2.4 距離の測り方

- 判定範囲・猶予幅など「○マス以内」の距離は、**円（まっすぐな距離）で測る**。
- **補足**：正方形（縦・横それぞれのマス数）で測ると、斜め方向だけ約1.4倍離れていても範囲内になり、向きによって判定の甘さが変わる。円で測れば、斜めでも縦横でも同じ感覚になる。
- **【仮案・未確認】**（`TBD-04-8`）距離は実数のマス座標どうしのユークリッド距離で測り、「N マス以内」は N 以下（ちょうど N を含む）。データに書く整数の座標はマスの中心。くわしくは [04_surgery_area.md](04_surgery_area.md) 1.4・2章。

### 2.5 指の扱い

- **最初に触れた1本の指だけを扱い、2本目以降は無視する**（誤操作を防ぐため。2本指の操作が必要な機器は今は無い）。
- 指を離すまで、機器は持ち替えられない（持ち替えは次の操作から）。持ち替えの操作も最初の1本の指だけで行う。**スワイプ中の持ち替えはさせない**。
- 操作の位置は指の位置からずらさない。操作中は、指のまわりに機器の範囲（筆の大きさ、吸い口など）を大きめに表示する。本実装で実機を使って確かめてから再検討する（`TBD-05-14`）。
  - **補足**：位置をずらすと、狙った場所と操作の結果がずれて分かりにくい。
  - 機器の範囲の表示サイズは**見た目だけ**で、判定には使わない（表示サイズの値は `TBD-05-11`）。ヒールゼリーの筆の半径だけは判定にも使う（3.1）。
- **【仮案・未確認】**（`TBD-05-24`）
  - PC では、ポインタを押している間のキー入力（1〜6 キーの持ち替え）は無視し、離した後から有効にする。
  - ポインタが途中で中断されたとき（通知バーの表示など）は、「離した」と同じ扱いにする（成功済みの結果は戻さない）。
  - 最初の指より先に2本目の指が離れても何も起きない。最初の指が離れたら操作は終わり、残った2本目の指は新しい操作として扱わない（指をすべて離してから次の操作）。
- **指を押している最中にキャラクター絵つきの会話（治療を止める会話）が始まったら**、会話をすぐに出し、その操作は「離した」と同じ扱いにする（決定、2026-10-03。[02_screens.md](02_screens.md) 3.4）。

### 2.6 音

- 医療機器は**操作中の音**（塗る・吸う・切るなど）を持つ。病巣は**結果の音**（発生・段階の完了・治療の完了）を持ち、医療機器の音と重ねて鳴らす。
- 病巣の処置時の音は、病巣データで手順の段階ごとに指定できる（指定が無ければ共通の「段階の完了」音）。
- **空振り・失敗・無効の音は、医療機器ごとに個別に持つ**（結果として同じ SE を指定する場合でも、それぞれ持つ）。

### 2.7 持ち替え

- ゲーム開始時はヒールゼリーを選択した状態にする。アイコンをタップして持ち替える（PC は 1〜6 キーでも可）。詳しくは [01_overview.md](01_overview.md) 3.2。

### 2.8 医療機器の強調表示

決定（2026-10-03）：

- **今使うべき医療機器**を、医療機器の列で強調表示する（「次に使う機器」ではない）。例：軽傷（切り傷）ならヒールゼリー、血溜まりがある病巣ならドレーン。
- 対象は、手術エリアに**出ている病巣それぞれの今の段階**の機器。病巣が複数あれば、複数の機器を強調する。出現前の病巣と治療済みの病巣は対象外。
- **省略できる段階**が今の段階のとき（例：切開の消毒＝ヒールゼリー）は、その段階の機器と、その次の段階の機器（例：メス）の**両方**を強調し、色で分ける。

| 機器 | 色 |
|---|---|
| 省略できる段階の機器（本来いま使うべきもの） | 通常の強調の色 |
| その次の段階の機器 | 薄い色 |

- **点滅のしかた**：強調の色を「1秒表示 → 0.5秒非表示 → 0.5秒表示 → 0.5秒非表示」の順で繰り返す（1周 2.5秒）。実際に試して調整する（`TBD-05-27`）。
- **注射（特定の病巣用の薬）**：注射のアイコンを強調し、注射を選んでいる間は、使う薬のボタン（3.6）も強調する。
- **特別機器（テーピング）は対象外**。テープは枠外から出てくる演出つきで現れるので、それ自体が案内になる（4章）。
- オン・オフの設定は設けない（常に表示する。暫定）。点数・評価には影響しない（評価の再検討に合わせて見直す可能性あり）。
- チュートリアル用に特定の機器を目立たせる仕組み（シナリオデータでの指定）は設けない（廃止）。ステージ1のチュートリアルも、この強調表示で足りるとする。
- 色・見た目の細部、ほかの選択中の表示との見分け方は `TBD-05-27`（画面・演出の検討（テーマ5））。

## 3. 各機器の仕様

### 3.1 ヒールゼリー

**用途**

- 軽度な裂傷の治療（癒着）
- メスで切開する前の消毒
- 腫瘍を摘出する前の生理食塩水の代わり
- 縫合針で縫合した後の癒着

**操作と結果**

| 項目 | 内容 |
|---|---|
| 操作方法 | 押して、なぞって塗る。指を離すまでが1回。**押した時点でストックを1消費する**（無効でも消費する） |
| 判定方法 | 筆（半径 N マスの円）でなぞった範囲を記録する。指を離した時点で、病巣のヒットエリアを**すべて**覆っていれば成功。1回で複数の病巣を塗れば、病巣ごとに判定する（まとめて治療できる） |
| 成功 | 病巣の手順が1段進む。回復は病巣データの回復値（無ければ既定値 1） |
| 失敗 | なし |
| 無効 | 覆いきれない（やり直せる）、手順違い、ストックが0 |
| 空振り | 塗っている間の回復（下記）だけが起きる |

**判定の手順**

1. 押す。ストックが1以上なら1消費して操作を始める。0なら無効（【仮案】ストック0のときは、下の「塗っている間の回復」も起きない。`TBD-05-17`）。
2. 押している間、筆の円が通ったマスを記録する。記録は病巣ごとに見る。
3. 指を離した時点で、病巣ごとに、そのヒットエリアのマスがすべて記録されているかを調べる。
   - すべて記録されている → 手順が合っていれば成功（手順が1段進む）。手順違い、または血溜まり・膿が残っている病巣 → 無効。
   - 1マスでも足りない → 無効（記録は破棄する。やり直すときは0から塗り直し、ストックをもう1つ使う）。
4. **【仮案・未確認】**（`TBD-05-16`）「覆った」とは、ヒットエリアの全マスについて、マスの中心が筆の円内を一度でも通ったこと。
5. **無効のとき、画面にメッセージは出さない**（決定。試作 v02 の P49 への回答、2026-10-02。無効の表示自体があまり必要ない）。音は機器データのとおり（2.6）。

**塗っている間の回復**

- 塗っている間は、成功・無効・空振りに関係なく（病巣の上でも、何も無い場所でも）バイタルが回復する。
- **押した瞬間に1回復**し、以後2秒ごとに1回復する（0秒・2秒・4秒…）。2秒未満で離しても1は回復する。
- 1回（ストック1回分）の回復は**最大10**まで。10に達するのは押してから18秒後。10に達した後も塗り続けられる（回復はしないが、覆う判定は続く）。
- 病巣の治療に成功したときは、これとは別に病巣データの回復値を足す。
- **補足**：病巣によるバイタル減少もあるため、高い難易度で必要になる想定。ステージごとの上限は設けず、ストック数とストックの回復時間が事実上の上限になる。
- 回復の強さ（試作 v02 の P47・P48：押し続けると回復が強すぎる、ゆっくり塗るほど得になる）は、**後日調整する**（2026-10-02 のユーザー回答）。バランスの検討（テーマ4）で扱う。

**ストックの回復**（【仮案・未確認】、`TBD-05-17`）

- ストックが満タン（5回）未満の間、5秒ごとに1回分ずつ回復する（塗っている間も進む。満タンで止まる）。ゲーム開始時は満タン。ステップをまたいでも引き継ぐ。リトライ・ステージ開始のときは満タンに戻す（[07_data_format.md](07_data_format.md) 5.7）。

**医療機器データに持つ値**

| 項目 | 値 |
|---|---|
| ストック数 | 5回（決定値） |
| ストックの回復時間 | 5秒で1回分（決定値） |
| 塗っている間の回復 | 押した瞬間に 1、以後 2秒ごとに 1（決定値） |
| 1回あたりの回復の上限 | 10（決定値） |
| 成功時の既定の回復値 | 1（決定値） |
| 筆の半径 | 未定（`TBD-05-11`） |

- 流血や膿がある状態では効かない（無効。[06_lesions.md](06_lesions.md) 1章）。

### 3.2 ドレーン

**用途**

- 流血や膿の吸い出し

**操作と結果**

| 項目 | 内容 |
|---|---|
| 操作方法 | 押し続ける。押したまま動かせる |
| 判定方法 | 押している位置が病巣のヒットエリア内にある間、病巣の量が減っていく |
| 成功 | 量が0になったら、病巣の手順が1段進む |
| 失敗 | なし |
| 無効 | 吸う物（血溜まり・膿）が無い病巣の上 |
| 空振り | 何も起きない |

**判定の手順**

1. 押している間、0.1秒ごとに、押している位置を調べる。
2. 位置が、吸う物（血溜まり・膿）がある病巣のヒットエリア内なら、その病巣の量を 0.1秒あたり1 減らす（決定値）。吸う物が無い病巣の上なら無効。ヒットエリアの外なら空振り（何も起きない）。
3. 量が0になったら成功（病巣の手順が1段進む）。
4. **【仮案・未確認】**（`TBD-05-18`）量は整数（単位は「量」）。ヒットエリアの外に出ている間は減らない（指は離さなくてよい。押したまま動かせる）。自然増は吸っている間も働く。吸った量は、離しても元に戻らない（自然増で増えるだけ）。

- 病巣側は、量・時間による自然増（出血のようなイメージ）・最大値を持つ（[07_data_format.md](07_data_format.md) 4章）。大きい血溜まりほど吸い切るのに時間がかかる。
- ゴミなど物を吸えるかは、**病巣ごとに決める**（物も病巣の一種なので、病巣データの治療手順で決まる）。ドレーン側に「ごみを吸う」機能は持たせない。基本的には、物を動かすのはピンセットで行う。

**医療機器データに持つ値**

| 項目 | 値 |
|---|---|
| 吸い出し速度 | 0.1秒あたり 1（決定値） |
| ストック | 無し（回数の制限なく使える。元の memo の仕様） |

### 3.3 ピンセット

**用途**

- 物を移動させる場合はすべてピンセットで行う。
- 例：破片・異物・腫瘍を取り出す、血管などを決まった位置へ動かす。
- 裂傷の段階での使い方は、病巣の再整理（テーマ3）で決める（`TBD-06-8`）。

**操作と結果**

| 項目 | 内容 |
|---|---|
| 操作方法 | 対象の上で押して掴み、押したままドラッグして運び、**運び先で離す** |
| 判定方法 | 掴む：押し始めた位置が対象のヒットエリア内か。運ぶ：指を離した位置が運び先か |
| 成功 | 運び先で指を離した時点で成功。病巣の手順が1段進む |
| 失敗 | 運び先以外で指を離した（手術エリアの中・外とも）。ダメージは病巣データ、無ければ既定値。物は**元の位置に戻る**（掴んでいる間は元の位置に薄い影＝ヒットエリアを残す） |
| 無効 | 掴めない物の上（手順違いを含む） |
| 空振り | 何も起きない |

**判定の手順**

1. 押した位置を調べる。対象（掴める物）のヒットエリア内 → 掴む。掴めない物（手順違いを含む）の上 → 無効。何も無い場所 → 空振り（何も起きない）。
2. 掴んでいる間、物は指に付いて動く。物の見た目は病巣データの元の見た目をそのまま使い、掴んだ位置を基準に平行移動して指に追従する（円などに描き替えない）。元の位置には薄い影（ヒットエリア）を残す。この表示のためのデータは増やさない（決定。試作 v02 の P52 への回答、2026-10-02）。運び先がトレイの物は、掴んだ時点で、トレイが**画面の枠外から空白エリアに出てくる演出つき**で表示される（移動先だと分かるようにするため。決定、2026-10-03。演出の細部は `TBD-05-28`）。
3. 指を離した位置を調べる。運び先（トレイ、または既定の位置の判定の範囲内）なら成功。それ以外（手術エリアの中・外、医療機器の列の上を含む）なら失敗（ダメージ）で、物は元の位置に戻る。
4. トレイを離して消す。

**運び先**

| 対象 | 運び先 |
|---|---|
| 不要物（破片・異物・腫瘍など） | **トレイ**。掴んでいる間だけ、医療機器の反対側の空白エリア（[04_surgery_area.md](04_surgery_area.md) 1.3、幅 260 × 高さ 890）に、枠外から出てくる演出つきで表示し、離したら消す |
| 血管など、決まった位置へ動かす物 | **既定の位置**。病巣データ（または配置）に持つ。判定の範囲（例：2マス以内）を持たせ、掴んでいる間は位置を表示する |

- トレイは手術エリアの外にあるので、掴んでいる間は手術エリアの外までドラッグできる（最初の指のまま）。トレイまでの距離は、この仕様で問題ない（試作 v02 の P51 への回答。実機での使いやすさは本実装でも確認する）。
- **掴んでいる物（ピンセットで運ぶ物）は、画面の最上位レイヤーに描く**（決定。試作 v02 の P53 への回答）。字幕エリア・バイタルゲージ・残り時間・医療機器の列の上にも重ねて表示する。問題が出たら再検討する。
- 決まった位置へ動かす物が最初のゴールで必要かは、ステージ2以降の手術内容（テーマ8）で確認する（`TBD-05-13`）。
- **【仮案・未確認】**（`TBD-05-19`）トレイの判定領域は、空白エリア全体（幅 260 × 高さ 890）。医療機器を右側にした場合は、トレイも反対側（左側）の空白エリアに表示する。掴んでいる物の表示は、指の位置に重ねる。

**医療機器データに持つ値**

| 項目 | 値 |
|---|---|
| 失敗の既定ダメージ | 未定（`TBD-05-11`） |

### 3.4 メス

**用途**

- 切開
- 攻撃（ギルス系に対して。名称は `TBD-04-5`）

**操作と結果**

| 項目 | 内容 |
|---|---|
| 操作方法 | 1回のスワイプ／ドラッグでなぞって切る |
| 判定方法 | 通過点（下記）を順番どおりに通ったか、猶予幅を外れていないか |
| 成功 | 最後の通過点に着いた時点で成功（指を離す必要はない） |
| 失敗 | 猶予幅を外れた、線状で端以外から切り始めた、通過点を飛ばした、手順違い。ダメージは病巣データ、無ければ既定値 2。失敗した時点でその操作は終わる |
| 無効 | すべての通過点を通る前に離した（やり直せる） |
| 空振り | ダメージ（2）＋**小さな切り傷**（ヒールゼリーだけで治る病巣。[06_lesions.md](06_lesions.md) 3.6）を切った場所に発生させる。ほかの病巣と重なる場所には発生させない（ダメージだけ）。軌跡が短い（例：2マス未満）ときは切ったとみなさず、何も起きない |

- **補足**：空振りで発生させる病巣を裂傷（4段階の処置が必要）にすると重すぎるため、小さな切り傷にする。タップしただけで病巣が出ないように、短い軌跡は無視する。

**判定の手順**

1. 押した位置を調べる。
   - 線状の切開線：端の通過点の判定範囲内 → 切り始めてよい（どちらの端からでもよい。端から端へ進む）。端の判定範囲の外でも、切開線の猶予幅以内 → **失敗**（端以外から切り始めた）。猶予幅の外 → 空振り。【仮案・未確認】この境目は `TBD-05-20`。
   - 円形（閉じた線）：どの通過点の判定範囲内からでも切り始めてよい（向きも自由）。点と点の間（線の途中）から始めた場合の扱いは、下の「切開の判定」（決定）。
   - 手順違い（今の段階がメスではない病巣の上）→ 失敗。
2. 以後、軌跡が**現在の目標の通過点**の判定範囲に入ったら、その点を通過したとみなし、目標を次の通過点に進める（線状は最初に押した端と反対の向きへ、円形は最初に通った点が起点、次に通った点で向きが決まる）。【円形の起点・向きの確定のしかたは仮案。`TBD-05-20`】
3. 軌跡が、今の通過点から次の通過点への直線から**猶予幅**を超えて外れたら失敗（ダメージ）。その時点で操作は終わる。
4. **通過点の順番を飛ばしたら失敗**：現在の目標以外の通過点の判定範囲に入ったら「飛ばした」とみなす（飛ばしてから戻って通るのも失敗）。（P40 決定：「飛ばした」は目標以外の通過点の判定範囲に入ったら失敗のまま。通過済みの点を通ること自体は失敗にしない。通過点どうしの間隔は、上のデータ作成のルールで対処する。【通過済みの点の扱いは仮案。`TBD-05-20`】）
5. 最後の通過点に着いた時点で成功（指を離す必要はない。円形は、すべての点を通って始めた点に戻った時点）。
6. すべての通過点を通る前に指を離したら無効（やり直せる。ダメージなし）。
7. 押した位置が病巣の判定領域の外だった場合（空振り）、軌跡が最短の長さ（例：2マス）に達した時点で、ダメージ（2）と小さな切り傷の発生を1回だけ行う。達しないまま離したら何も起きない。

**切開の判定**

- 切開する線は、判定データとして**通過点の座標のリスト**（マス座標 [x, y]）で持つ。
  - 例：斜めの線なら `[0,0]` `[5,5]` `[10,10]` の3点（病巣データでは配置の位置を [0, 0] とした相対座標。`TBD-07-12`）。
  - 通過点どうしはあえて隣り合わせない。本家の仕様にならったものであり、点が密すぎると操作に精密さが求められすぎて操作性が悪くなるため。
  - **データ作成のルール**（決定。試作 v02 の P40 への回答、2026-10-02）：隣り合う通過点は判定範囲の直径（例：4マス）より離す。隣の隣の通過点とは判定範囲が重ならないようにする。曲がり角で点を内側に寄せすぎない。これは**データ作成の制約**で、判定のロジックは変えない（下の「飛ばした」の定義のまま）。具体値は `TBD-05-11`。
- 判定には次の2つの幅を使う（距離は円で測る。2.4）。

| 項目 | 内容 | 例（決定ではない） |
|---|---|---|
| 通過点の判定範囲 | 操作の位置が通過点からこの範囲内に入れば、その点を通過したとみなす | 2マス以内 |
| 線からの猶予幅 | 通過点から次の通過点を直線で結び、操作の軌跡がこの幅を超えて外れたら失敗 | 3マス |

```
  [0,0] ●──────────────────────────────
         ＼  ← 点と点を結んだ直線
          ＼   その両側に猶予幅（例：3マス）
     判定範囲 ○ [5,5]   ← 点のまわり（例：2マス以内）を通れば通過
             ＼
              ＼
                ● [10,10]
```

| 線の形 | 切り始める位置 | 向き |
|---|---|---|
| 線状（端のある線） | **どちらかの端の通過点**。端以外から切り始めたら失敗（ダメージ） | 端から端へ |
| 円形（閉じた線。腫瘍の周りなど） | **どの通過点からでもよい**。すべての点を通って始めた点に戻れば成功 | 自由 |

- **通過点は順番どおりに通る**。飛ばして先の点に着いたら失敗（ダメージ）。飛ばしてから戻って通るのも失敗。
- **円形を、点と点の間（線の途中）から始めた場合**（決定。試作 v02 の P41 への回答、2026-10-02）：その位置を含む線の両端のどちらかの通過点へ進み、一周して始めた位置に戻れば成功とする。
- 2つの幅の値は医療機器データに基本値として持つ。**病巣ごとの上書きはせず、医療機器ごとに固定する**（[07_data_format.md](07_data_format.md) 3章）。係数（ステージ補正・難易度）は掛けない【仮案・未確認】（空間の大きさなので、難易度で操作感を変えない。[03_game_rules.md](03_game_rules.md) 6.2、`TBD-03-8` で確定）。

**医療機器データに持つ値**

| 項目 | 値 |
|---|---|
| 通過点の判定範囲 | 例：2マス（`TBD-05-11`） |
| 線からの猶予幅 | 例：3マス（`TBD-05-11`） |
| 失敗の既定ダメージ | 2（決定値） |
| 空振りのダメージ | 2（決定値） |
| 空振りで発生させる病巣 | 小さな切り傷（決定。形・大きさ・完了条件は 06 3.6） |
| 「切った」とみなす最短の長さ | 例：2マス（`TBD-05-11`） |

### 3.5 縫合針

**用途**

- 裂傷の縫合
- 外科的切開の縫合

**操作と結果**

| 項目 | 内容 |
|---|---|
| 操作方法 | **1回のスワイプで**、通過点を繋いだ線をまたぐようにジグザグに縫う |
| 判定方法 | 判定データとして通過点の座標を持つ（メスと同じ形）。通過点を繋いだ線を、操作の軌跡がまたいだ回数を数える |
| 成功 | **指を離した時点で、またいだ回数が通過点の数以上**なら、病巣の手順が1段進む（例：通過点3個なら3回以上） |
| 失敗 | 線から猶予幅の外に出た。ダメージは病巣データ、無ければ既定値 1 |
| 無効 | 指を離した時点で、またいだ回数が通過点の数に足りない。またいだ回数は0に戻る（やり直せる。ダメージなし） |
| 空振り | ダメージ（1）。縫う段階ではない病巣の上で縫ったときも空振りとして扱う（2.1、2.2） |

**判定の手順**

1. 押した位置を調べる。縫う段階の病巣の判定領域（通過点を繋いだ線から猶予幅以内）の内側 → その病巣を縫う。縫う段階ではない病巣の上、または何も無い場所 → 空振り（ダメージ 1。**押した瞬間**に1回。決定、P37）。
   - 押した位置が複数の縫う段階の病巣の近くにあるときは、**押した位置に最も近い線**を縫う対象にする（決定、P38）。
2. またいだ回数を0から数え始める。
3. 軌跡が、通過点を繋いだ線を横切るたびに、またいだ回数を1増やす。**またぐ場所・順番は問わない**。全く同じ箇所の往復でも数える。
   - 通過点の数と同じ回数またぐ。例：5回またぐ ＝ 2往復半（「5往復」ではない）。通過点を増やせば必要な回数を調整できる。
   - この回数は**最低ノルマ**。それ以上またいでもよい（余分にまたいでも失敗にならない）。
   - 【仮案・未確認】（`TBD-05-21`）「線」は、通過点を順に繋いだ折れ線（線分の延長は含まない）。手ぶれで同じ線を行き来して数が増えないよう、線から猶予幅の 1/3 以上離れてから戻った場合のみ、再び横切ったと数える。
4. 軌跡が線から猶予幅の外に出たら失敗（ダメージ）。その時点で操作は終わる。
5. **指を離した時点**で、またいだ回数が通過点の数以上なら成功（病巣の手順が1段進む）。離した時点の回数で判定する（規定の回数に達しただけでは成功にならない）。
6. 離した時点で、またいだ回数が通過点の数に足りなければ無効（回数は0に戻り、やり直せる。ダメージなし）。

- **またぐ場所・順番は問わない**。全く同じ箇所の往復でも、またぐ回数を満たして離せば成功とする。長い傷でも一か所で縫い切れる（通過点を増やして回数を調整する。P39 への回答）。
- 猶予幅は**かなり広く取る**。
- **補足**：初心者には縫合の操作の理解が意外と難しいため、場所を問わないこと、猶予幅を広く取ることは救済措置を兼ねる。

```
   通過点を繋いだ線（●─●─●）をまたぐようにジグザグに縫う
       ／＼    ／＼
   ●──────●──────●     ← またいだ回数が通過点の数（3）以上で指を離したら成功
     ＼／    ＼／
```

**医療機器データに持つ値**

| 項目 | 値 |
|---|---|
| 失敗の既定ダメージ | 1（決定値） |
| 空振りのダメージ | 1（決定値） |
| 線からの猶予幅 | 広め（値は未定。`TBD-05-11`） |

### 3.6 注射

**用途**

- バイタル回復剤の注入
- 麻酔の注入
- その他の治療薬・特効薬の注入（特定の病巣に打つ薬）

**操作と結果**

| 項目 | 内容 |
|---|---|
| 操作方法 | 手術エリアを**押している間、ゲージを消費して注入する**（離すと止まる） |
| 判定方法 | 回復剤・麻酔：手術エリアのどこに打ってもよい。特定の病巣用の薬：押した位置が対象の病巣のヒットエリア内か |
| 成功 | 注入量に比例した効果（回復剤は回復、麻酔は効果時間）。特定の病巣用の薬は、必要量を入れると病巣の手順が1段進む |
| 失敗 | 薬による（手順違いでダメージになる薬もある。2.2） |
| 無効 | ゲージが0 |
| 空振り | 回復剤・麻酔には無い（どこでも効く）。特定の病巣用の薬は、**タップした時点でダメージ 1**、注入はしない（ゲージも減らない）。対象外の病巣に打ったときも空振りとして扱う（2.1） |

**判定の手順**

1. 押す。ゲージが0なら無効（何も起きない）。
2. 回復剤・麻酔：手術エリアのどこでも、押している間ゲージを消費して注入する（手術エリアの外では何も起きない）。
3. 特定の病巣用の薬：押した位置を調べる。対象の病巣のヒットエリア内で、手順が合っている → 押している間注入する（必要量に達したら成功）。**判定の位置は最初に押した位置で固定**（決定、P44）。押したまま動かしても判定位置は変わらず、病巣の外へ動いても注入は続く。ヒットエリアの外、または対象外の病巣の上 → 空振り（ダメージ 1、注入しない、ゲージも減らない）。手順違い（対象の病巣の別の段階）→ 薬ごとに、無効または失敗（ダメージ）。
4. 注入量が、その患者のその薬の限度量を**上回った**瞬間にゲームオーバー（押している最中でも）。【単位と判定の細部は仮案。`TBD-05-22`】限度量を超える瞬間の特別演出と警告の出し方は後日検討（`TBD-05-12`、P45・P50）。

- ゲージの回復中も使えるが、効果は注入量に比例する。
- 薬を切り替えてもゲージはリセットされない。
- 麻酔の効果時間・減少緩和率の基本値はこのデータに持ち、ステージ係数と難易度係数で補正する（[03_game_rules.md](03_game_rules.md) 1.3・6章）。
- **麻酔は重ねがけできる**（残り時間に効果時間を足す）。

**薬の切り替え**

- 注射を選んでいる間、薬のボタンを表示し、1回のタップで選べるようにする。今の薬は常に強調表示する（選択中の表示。2.8 の「今使うべき薬」の強調表示とは別）。
- **薬ボタンの位置**（決定。試作 v02 の P36 への回答、2026-10-02）：注射アイコンの**横（手術エリア側）**に出し、薬の種類のボタンは**上方向**に並べる。ほかの領域（手術エリア・字幕エリアなど）に重なってよく、**最上位レイヤー**で描く。
- **手術の開始直後は回復剤**を選んだ状態にする。別の薬を選んだら、次に注射を選んだときもその薬のまま（最後に選んだ薬を覚えておく）。
- **補足**：今どの薬かがひと目で分かり、薬が増えても対応できる。
- 【仮案・未確認】（`TBD-05-25`）「手術の開始直後」は、ステージ開始時とリトライ時。ステップが変わっても選んだ薬は保持する。PC のキー（例：7〜9）は未定（薬ボタンの位置は上のとおり決定）。

**限度量（大量投与）**

- **患者ごとに、薬剤別の限度量**を設ける（1ステージに複数の患者がいる場合もあるため）。
- 時間による減少は考えず、**投与の絶対量（その患者への累計）で判定**する。限度量を超えたらゲームオーバー（[03_game_rules.md](03_game_rules.md) 3章）。
- 麻酔は限度量を設ける想定。ほかの薬にも似た決まりを設ける場合がある（薬による）。限度量を持たない薬（回復剤など）は無制限。
- 限度量に近づいたら警告する。できればメッセージで警告し、画面上で分かる表現もあるとよい（表現は画面・演出の検討（テーマ5）で決める。`TBD-05-12`）。
- 置き場所：薬ごとの既定の限度量を医療機器データに持ち、ステージデータの患者ごとに上書きできる（[07_data_format.md](07_data_format.md) 3章・5章）。
- **【仮案・未確認】**（`TBD-05-22`）
  - 注入量の単位は「ゲージ消費量」（ゲージ満タン＝100）。限度量も同じ単位で書く。累計は患者ごとで、ステージの中では引き継ぎ、リトライでリセットする（[07_data_format.md](07_data_format.md) 5.7）。
  - 麻酔の効果時間＝基本の効果時間 × 消費量 ÷ 100。回復剤の回復量＝20 × 消費量 ÷ 100（満タンを使い切ると20。値 20 は元案で `TBD-03-4`）。
  - 限度量を超えそうなときの救済・演出（止める、警告を強くするなど。P45）は後日検討（`TBD-05-12`）。
- 麻酔の限度量と効果時間の釣り合い（試作 v02 の P46）は、後日調整する（2026-10-02 のユーザー回答）。「限度量＝効果時間の合計の上限」になる点を前提に、バランスの検討（テーマ4）で決める。

### 4.1 テーピング

6つの医療機器とは別の**特別機器**（決定、2026-10-02）。医療機器の列には並べず、1〜6 キーにも入れない。持ち替えも不要。以下は 2026-10-03 の決定。

**使うタイミング**

**テープの出し方**

- テーピングを行える状態になると、テープが**トレイと同じ位置（空白エリア）に、画面の枠外から出てくる演出つき**で現れる。出てくる演出があるので、強調表示（2.8）はしない。
- テープが現れるタイミングの細部、消えるタイミングは `TBD-05-26`。演出の細部は `TBD-05-28`。

**操作と結果**

| 項目 | 内容 |
|---|---|

**医療機器データに持つ値**

- 医療機器データの中の「特別機器」の枠に持つ（上書きの順番・係数の仕組みを6つの機器と共通に使う。[07_data_format.md](07_data_format.md) 3章）。具体的な値は `TBD-05-26`、`TBD-05-11`。
