## 2. 共通ルール

- ゲーム開始時はヒールゼリーを選択した状態にする。アイコンをタップして持ち替える（PC は 1〜6 キーでも可）。詳しくは [01_overview.md](01_overview.md) 3.2。
> **注意**：この章と各機器の「空振り・ミス・回復」に関する記述は、検討中に思いついた内容を書いた段階で、**まだ整合が取れていない**。各値をどのデータに持たせるかの基本ルールは決まった（[07_data_format.md](07_data_format.md) 2章：空振りは医療機器データ、成功は病巣データ、失敗は病巣データ（無ければ医療機器データの既定値））。機器ごとの値はこのルールに沿って再整理する。医療機器と病巣の仕様はまとめて再整理する（`TBD-05-1`、`TBD-05-10`）。

- 医療機器側で持つダメージは、病巣の無い場所を誤って操作したときに発生する。
- 医療機器側で持つ回復も、同様に病巣の無い場所で発生する。
- 機器ごとの空振り時の扱いは `TBD-05-1`。

## 3. 各機器の仕様

### 3.1 ヒールゼリー

**用途**

- 軽度な裂傷の治療（癒着）
- メスで切開する前の消毒
- 腫瘍を摘出する前の生理食塩水の代わり
- 縫合針で縫合した後の癒着

**仕様**

| 項目 | 値 |
|---|---|
| 回復量 | 1回の塗布ごとにバイタル 1 |
| ストック | 5回 |
| ストック回復 | 3秒ごとに1回分 |

- 塗布中は指（カーソル）の移動に追従する。まとめて治療できる（裂傷など）。
- 指を離すまでが1回。
- 長い傷の場合、1回で全体を覆わないと成功扱いにならない。この場合は**無効**（ダメージなし、やり直しできる）とする。
- 「全体を覆った」とみなす判定方法は、医療機器と病巣の再整理の中で決める（`TBD-05-10`）。
- 流血や膿がある状態では効かない。

### 3.2 ドレーン

**用途**

- 流血や膿の吸い出し
- ごみの除去にも使えるか（刺さっていない金属片など）：`TBD-05-3`

**仕様**

| 項目 | 値 |
|---|---|
| ストック | 無し（無限に使える） |
| ミス判定 | 無し |
| 回復判定 | 無し |

- 吸い出しの速度は `TBD-05-4`。

### 3.3 ピンセット

**用途**

- 物を移動させる場合はすべてピンセットで行う。
- 例：血管の移動、骨や銃弾を拾い上げる。

**仕様**

- 移動中に落とした（指を離した）場合はミス判定。
- 運び先・落としたときのダメージ量は `TBD-05-5`。

### 3.4 メス

**用途**

- 切開
- 攻撃（ギルス系に対して）

**仕様**

| 項目 | 値 |
|---|---|
| ミス時のダメージ | 2 |

- 病巣の無い場所に当てると裂傷が発生する。

**切開の判定（検討中の案）**

> **注意**：以下はユーザーが判定方法の**例**として挙げた案で、確定ではない。なぞり操作の判定は医療機器ごとに仕様が異なるため、機器ごとに改めて検討する（`TBD-05-6`）。

- 切開する線は、判定データとして**通過点の座標のリスト**（マス座標）で持つ。
  - 例：斜めの線なら `[0,0]` `[5,5]` `[10,10]` の3点。
  - 通過点どうしはあえて隣り合わせない。本家の仕様にならったものであり、点が密すぎると操作に精密さが求められすぎて操作性が悪くなるため。
- メスを選んだ状態で、**1回の操作（スワイプ／マウスドラッグ）ですべての通過点を通過すれば成功（OK）**。
- 判定には次の2つの幅を使う。

| 項目 | 内容 | 例 |
|---|---|---|
| 通過点の判定範囲 | 操作の位置が通過点からこの範囲内に入れば、その点を通過したとみなす | 2マス以内 |
| 線からの猶予幅 | 通過点から次の通過点を直線で結び、操作の軌跡がこの幅を超えて外れたら失敗（NG） | 3マス |

```
  [0,0] ●──────────────────────────────
         ＼  ← 点と点を結んだ直線
          ＼   その両側に猶予幅（例：3マス）
     判定範囲 ○ [5,5]   ← 点のまわり（例：2マス以内）を通れば通過
             ＼
              ＼
                ● [10,10]
```

- 2つの幅の値は医療機器データに基本値として持つ。**病巣ごとの上書きはせず、医療機器ごとに固定する**（現時点の決定。[07_data_format.md](07_data_format.md) 3章）。係数（ステージ補正・難易度）の対象にできる（[03_game_rules.md](03_game_rules.md) 6章、`TBD-03-8`）。
- この案を採用する場合の未決の点：通過する順番、途中で指を離したときの扱い、NG 時の結果、距離の測り方（`TBD-05-6`）。

### 3.5 縫合針

**用途**

- 裂傷の縫合
- 外科的切開の縫合

**仕様**

| 項目 | 値 |
|---|---|
| ミス時のダメージ | 1 |

- 縫合の操作方法・判定方法は `TBD-05-6`。

### 3.6 注射

**用途**

- バイタル回復剤の注入
- 麻酔の注入
- その他の治療薬・特効薬の注入

**仕様**

| 項目 | 値 |
|---|---|
| ストック | 無し（時間でゲージが回復） |
| ゲージ回復 | ゼロから満タンまで 10秒 |
| 回復量（バイタル回復剤） | 1回の最大注入で 20（[03_game_rules.md](03_game_rules.md)） |
| ヒットエリア | 3×3 マス（[04_surgery_area.md](04_surgery_area.md)） |

- ゲージの回復中も使えるが、効果は注入量に比例する。
- 薬を切り替えてもゲージはリセットされない。
- 麻酔の効果時間・減少緩和率の基本値はこのデータに持ち、ステージ係数と難易度係数で補正する（[03_game_rules.md](03_game_rules.md) 1.3・6章）。
- 薬の切り替え操作は `TBD-05-7`。
