# 07 データ仕様

- ステータス：草案

## 1. データ形式

- JSON を候補とする（`TBD-07-1`）。

## 2. データの種類と基本ルール

値をどのデータに持たせるかの基本ルール（[_records/2026-09-25_data_ownership_draft.md](../_records/2026-09-25_data_ownership_draft.md) の R1〜R7 で決定）。

### 2.1 データの種類

| データ | 何を表すか | 考え方 | 例 |
|---|---|---|---|
| 医療機器データ | 道具そのものの性能 | **どの病巣・どのステージでも同じ値**になるもの | ストック数、ヒットエリア、空振りしたときの結果 |
| 病巣データ（種類） | 病巣の「ひな形」 | **その種類の病巣なら、どこに出ても同じ**になるもの | 切り傷の治療手順、成功時の回復値、SE |
| ステージデータ | その手術の状況 | **その場面だけ**のもの | 開始時のバイタル、どの病巣を・どこに・いつ出すか |
| システムデータ | ゲーム全体の調整用の値 | ステージによらず、ゲーム全体に掛かるもの | 難易度ごとの係数 |

- 病巣は「種類」（病巣データ）と「配置」（ステージデータ）に分けて持つ。同じ種類の病巣を何度も書かずに済むようにするため。

| | 置き場所 | 持つもの |
|---|---|---|
| 病巣の**種類** | 病巣データ | 見た目、SE、判定データの形、治療手順、回復値・ダメージ値、時間による変化 |
| 病巣の**配置** | ステージデータ | どの種類を・どこに（マス座標）・いつ出すか（出現条件）、この配置だけの上書き値 |

```
病巣データ（種類）        ステージデータ（配置）
┌──────────┐      ┌────────────────────┐
│ 切り傷           │ ←── │ 切り傷を [20,10] に、開始時に出す │
│  手順：ゼリー     │ ←── │ 切り傷を [60,30] に、10秒後に出す │
│  回復：3         │      └────────────────────┘
└──────────┘
```

### 2.2 操作の結果の分類

操作の結果は、次の4つに分けて扱う。

| 結果 | 意味 | 例 |
|---|---|---|
| 成功 | 治療手順の1段階が完了した | 通過点をすべて通ってメスで切開できた |
| 失敗（NG） | 病巣に対して操作したが、やり方を誤った | メスが猶予幅を外れた、ピンセットで運ぶ途中に落とした、手順と違う機器を使った |
| 無効 | 操作したが何も起きない（ダメージも無い） | 長い傷をヒールゼリーで覆いきれなかった、血溜まりがあってゼリーが効かない |
| 空振り | 病巣の無い場所を操作した | 何も無い皮膚をメスで切った |

### 2.3 結果ごとの値の置き場所

| 結果 | 値の置き場所 | 理由 |
|---|---|---|
| 空振り | **医療機器データ** | 病巣が無い場所なので、道具の性質で決まる |
| 成功 | **病巣データ** | どれだけ回復するかは病巣によって違う |
| 失敗 | **病巣データ**（無ければ医療機器データの既定値） | 病巣ごとに重さが違う。ただし毎回書くのは大変なので、機器の既定値を使えるようにする |
| 無効 | 値は持たない | 何も起きないため |

### 2.4 上書きの順番

同じ値が複数の場所にあるときは、**より具体的なほうを優先**する。

```
医療機器データの既定値
   ↓ 病巣データに指定があれば上書き
病巣データ（種類）の値
   ↓ ステージの配置に指定があれば上書き
配置ごとの値
   ↓ 最後に係数を掛ける（03_game_rules.md 6章）
実際の値 ＝ 上の値 × ステージ係数 × 難易度係数
```

- 例：メスの失敗ダメージ
  - 医療機器データ（メス）の既定値：2
  - 病巣データ（切開）に指定が無ければ 2 を使う
  - 病巣データ（腫瘍の切除）で 4 と指定すれば、腫瘍のときだけ 4 になる
- 上書きできない値もある（例：なぞり操作の判定範囲・猶予幅は医療機器データに固定。3章）。

## 3. 医療機器データ

- 医療機器のパラメータはデータファイルとして持つ（[08_assets.md](08_assets.md) のフォルダ構成）。項目の詳細は [05_instruments.md](05_instruments.md) 参照。

| 値 | 今の仕様（出典） | 補足 |
|---|---|---|
| ヒールゼリーのストック数・回復時間 | 5回、3秒で1回分（05 3.1） | - |
| 注射のゲージ回復時間 | 10秒（05 3.6） | - |
| 薬ごとの効果（回復剤の回復量、麻酔の効果時間・減少緩和率） | 最大 20 回復など（05 3.6、03 1.3） | 薬ごとに値を持つ |
| ヒットエリアの大きさ | 注射は 3×3（04 2章） | - |
| なぞり操作の判定範囲・猶予幅 | メスの案：2マス・3マス（05 3.4） | **医療機器ごとに固定**。病巣ごとの上書きはしない（現時点の決定） |
| 空振りの結果 | ヒールゼリー：回復1、メス：ダメージ2＋裂傷の発生（05） | 結果の種類（ダメージ／回復／病巣の発生／なし）と値 |
| 失敗の既定値 | メス：2、縫合針：1（05） | 病巣データで上書きできる |

## 4. 病巣データ（種類）

各病巣の種類について、次の情報を持つ。置く位置と出すタイミングはステージデータ（5.3）に持つ。

| 項目 | 内容 | 出典・補足 |
|---|---|---|
| 見た目 | 表示する画像 | [04_surgery_area.md](04_surgery_area.md) 2章 |
| SE | 発生時の音、処置時の音 | 処置時の音は手順の段階ごとに持てるようにする（`TBD-07-6`） |
| 判定データ | 治療の成否を判定するための形（マス座標。案：切開線は通過点のリスト）。形そのものを持ち、置く位置は配置で決める | [04_surgery_area.md](04_surgery_area.md) 2章、[06_lesions.md](06_lesions.md) 3.5 |
| 治療手順 | 医療機器を使う順番（例：ドレーン → ピンセット → 縫合針 → ヒールゼリー）。省略できる段階と、省略したときのダメージも持つ（例：切開のヒールゼリー） | [06_lesions.md](06_lesions.md) |
| 成功時の回復値 | 手順の段階ごと | - |
| 失敗時のダメージ値 | 手順の段階ごと。無ければ医療機器データの既定値 | - |
| 失敗時の扱い | 最初に戻るか、戻らないか | `TBD-06-3` |
| バイタル減少 | 病巣があるあいだの減少の間隔と量（病巣ごとに独立して処理する） | [03_game_rules.md](03_game_rules.md) 1.2 |
| 時間による変化 | 何秒後に、どう変わるか（例：裂傷の再出血） | [06_lesions.md](06_lesions.md) 3.2 |
| 他の治療を妨げる状態 | 「無効」になる条件（例：血溜まり・膿があるとヒールゼリーが効かない） | [06_lesions.md](06_lesions.md) 1章 |

- 病巣は重ならない。
- 病巣の種類ごとの仕様は [06_lesions.md](06_lesions.md) 参照。

## 5. ステージデータ

### 5.1 構成

- ステップごとの配列で持つ。
  - 例：1ステップ目は切開（開腹）、2ステップ目は内臓、など。
- ステップ単位で、処理順の配列を管理する。

### 5.2 ステージ全体で持つ値

| 項目 | 内容 |
|---|---|
| 開始時のバイタル | 0〜99 |
| 自然減少 | 間隔と量（病巣による減少とは独立して処理する） |
| 制限時間 | 秒数 |
| 時間切れの会話 | 時間切れのときに表示する会話 |
| 点数の条件 | 加点の条件と点数（`TBD-03-3`） |
| ステージ係数 | 項目ごとの補正係数。指定しない項目は 1.0（[03_game_rules.md](03_game_rules.md) 6章） |

### 5.3 病巣の配置

処置データの中に、病巣の配置を並べる。

| 項目 | 内容 |
|---|---|
| 病巣の種類 | 病巣データ（4章）のどれを使うか |
| 位置 | 病巣を置くマス座標 |
| 出現条件 | いつ出すか（開始時、○秒後、他の病巣の完了後など。`TBD-07-2`） |
| 上書き値 | この配置だけ変えたい値（2.4 の上書きの順番に従う） |

### 5.4 処理順の例（会話 → 処置 → 会話）

```
ステップ
├── 会話データ（治療前の会話）
├── 処置データ
│   ├── 病巣の配置1 を展開（種類・座標など）→ 治療（ゲーム操作）
│   ├── 病巣の配置2 を展開（種類・座標など）→ 治療（ゲーム操作）
│   ├── 処置中の会話データ
│   └── 病巣が無くなったら次へ
└── 会話データ（治療後の会話）
```

- 病巣1と病巣2は同時に処理される。
- 処置中の会話は、治療操作と同期を取るのが難しいので流れっぱなしにする。
- ゲーム中のテキスト（処置中の会話・指示）はステージ側に持つ（[scenario.md](../scenario.md) の方針）。

### 5.5 処置内容の分岐

- 会話の選択肢（フラグ）によって、同じステージの中で処置データを切り替えられるようにする。
  - 例：ステージ3では、選択肢によって処置の内容（病巣の構成・手順）が変わる。シナリオの結果は変わらない。
- ステージ選択時の難易度（係数による数値の補正、[03_game_rules.md](03_game_rules.md) 6.3）とは別の仕組み。
- 分岐の書き方（ステップ単位で切り替えるか、処置データ単位か）は `TBD-07-5`。

### 5.6 課題

- 上記の構成では処理が一本道（シングルスレッド）になっている。複数の病巣が同時多発する仕組みを考える必要がある（`TBD-07-2`）。

## 6. システムデータ

- ゲーム全体の調整用の値を持つ。ステージによらず、ゲーム全体に掛かるもの。
- 今は難易度だけを持つ。今後、調整用の値が増えることを想定している。
- 項目が多くなった場合は、内容ごとに専用のファイルに分ける（例：難易度だけを別のファイルにする）。

### 6.1 難易度

- 難易度ごとに、項目別の係数を持つ（[03_game_rules.md](03_game_rules.md) 6.3）。
- 実際の値 ＝ 基本値 × ステージ係数 × 難易度係数。

| 項目 | 内容 |
|---|---|
| 難易度 ID・名前 | 例：`easy`／やさしい（`TBD-03-9`） |
| 係数 | 係数の対象項目ごとの値（`TBD-03-8`） |

## 7. シナリオデータ

シナリオテキストに入れる情報：

| 項目 | 内容 |
|---|---|
| 背景画像 | 会話画面の背景 |
| 表示イラスト | 左右のキャラクター |
| SE | 効果音 |
| BGM | 音楽 |
| ボイス | 音声 |
| 医療機器の強調表示 | ON／OFF の設定（チュートリアルなどで使う） |

- テキストの書式は `TBD-07-3`。

- 保存する内容：クリア状況（開放済みステージ）、ランク、フラグ、オプション設定。
- 形式と保存のタイミングは `TBD-07-4`。
