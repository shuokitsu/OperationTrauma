# 07 データ仕様

- ステータス：草案
- 最終更新：2026-09-25

## 1. データ形式

- JSON を候補とする（`TBD-07-1`）。

## 2. 病巣データ

各病巣について、次の情報を持つ。

| 項目 | 内容 |
|---|---|
| 出現位置 | 病巣が出現する座標 |
| 病巣位置 | 病巣の座標 |
| 見た目 | 表示する画像 |
| 判定データ | 治療の成否を判定するための形（マス座標。案：切開線は通過点のリスト）。[04_surgery_area.md](04_surgery_area.md) 2章 |
| 治療順 | 医療機器を使う順番（例：ピンセット → ヒールゼリー） |
| 失敗時の扱い | 最初に戻るか、戻らないか |
| 回復値 | 成功時の回復値 |
| ダメージ値 | 失敗時のダメージ値 |
| バイタル減少 | 病巣があるあいだの減少の間隔と量（病巣ごとに独立して処理する） |

- 病巣は重ならない。
- 病巣の種類ごとの仕様は [06_lesions.md](06_lesions.md) 参照。

## 3. ステージデータ

### 3.1 構成

- ステップごとの配列で持つ。
  - 例：1ステップ目は切開（開腹）、2ステップ目は内臓、など。
- ステップ単位で、処理順の配列を管理する。

### 3.2 ステージ全体で持つ値

| 項目 | 内容 |
|---|---|
| 開始時のバイタル | 0〜99 |
| 自然減少 | 間隔と量（病巣による減少とは独立して処理する） |
| 制限時間 | 秒数 |
| 時間切れの会話 | 時間切れのときに表示する会話 |
| 点数の条件 | 加点の条件と点数（`TBD-03-3`） |
| ステージ係数 | 項目ごとの補正係数。指定しない項目は 1.0（[03_game_rules.md](03_game_rules.md) 6章） |

### 3.3 処理順の例（会話 → 処置 → 会話）

```
ステップ
├── 会話データ（治療前の会話）
├── 処置データ
│   ├── 病巣データ1 を展開（座標・対処法など）→ 治療（ゲーム操作）
│   ├── 病巣データ2 を展開（座標・対処法など）→ 治療（ゲーム操作）
│   ├── 処置中の会話データ
│   └── 病巣が無くなったら次へ
└── 会話データ（治療後の会話）
```

- 病巣1と病巣2は同時に処理される。
- 処置中の会話は、治療操作と同期を取るのが難しいので流れっぱなしにする。
- ゲーム中のテキスト（処置中の会話・指示）はステージ側に持つ（[scenario.md](../scenario.md) の方針）。

### 3.4 処置内容の分岐

- 会話の選択肢（フラグ）によって、同じステージの中で処置データを切り替えられるようにする。
  - 例：ステージ3では、選択肢によって処置の内容（病巣の構成・手順）が変わる。シナリオの結果は変わらない。
- ステージ選択時の難易度（係数による数値の補正、[03_game_rules.md](03_game_rules.md) 6.3）とは別の仕組み。
- 分岐の書き方（ステップ単位で切り替えるか、処置データ単位か）は `TBD-07-5`。

### 3.5 課題

- 上記の構成では処理が一本道（シングルスレッド）になっている。複数の病巣が同時多発する仕組みを考える必要がある（`TBD-07-2`）。

## 4. シナリオデータ

シナリオテキストに入れる情報：

| 項目 | 内容 |
|---|---|
| 背景画像 | 会話画面の背景 |
| 表示イラスト | 左右のキャラクター |
| SE | 効果音 |
| BGM | 音楽 |
| ボイス | 音声 |
| 医療機器の強調表示 | ON／OFF の設定（チュートリアルなどで使う） |

- テキストの書式は `TBD-07-3`。

## 5. 治療器具パラメータ・難易度データ

- 医療機器のパラメータはデータファイルとして持つ（[08_assets.md](08_assets.md) のフォルダ構成）。
- 項目は [05_instruments.md](05_instruments.md) 参照。麻酔の効果時間・減少緩和率の基本値もここに持つ。

### 5.1 難易度データ

- 難易度ごとに、項目別の係数を持つ（[03_game_rules.md](03_game_rules.md) 6.3）。
- 実際の値 ＝ 基本値 × ステージ係数 × 難易度係数。

| 項目 | 内容 |
|---|---|
| 難易度 ID・名前 | 例：`easy`／やさしい（`TBD-03-9`） |
| 係数 | 係数の対象項目ごとの値（`TBD-03-8`） |

## 6. セーブデータ

- 自動セーブ。ブラウザのローカルストレージに保存する（[02_screens.md](02_screens.md) 4章）。
- 保存する内容：クリア状況（開放済みステージ）、ランク、フラグ、オプション設定。
- 形式と保存のタイミングは `TBD-07-4`。
