# 03 ゲームルール

- ステータス：草案
- 最終更新：2026-09-25

## 1. バイタル

### 1.1 基本

| 項目 | 値 |
|---|---|
| 範囲 | 0〜99 |
| 最大値 | 99 |
| 開始時の値 | ステージデータで指定する |
| ゲームオーバー | 0 になったとき |

### 1.2 増減

| 種類 | 内容 | 値 |
|---|---|---|
| 自然減少 | 一定時間ごとに下がる | 間隔と量を**ステージデータ**で指定する（例：2秒ごとに1） |
| 病巣による減少 | 病巣があると一定時間ごとに下がる | 間隔と量を**病巣データ**で指定する（[06_lesions.md](06_lesions.md)） |
| 治療成功 | 回復する | 病巣ごとに異なる |
| 治療ミス | ダメージを受ける | 医療機器ごとに異なる（[05_instruments.md](05_instruments.md)） |
| 注射 | 注入量に応じて回復 | 1回の最大注入で 20（本家の値を調べる：`TBD-03-4`） |

- 自然減少と病巣による減少は、**それぞれ独立したタイマーで個別に（非同期で）判定・処理する**。
  - 例：自然減少が「2秒ごとに1」、病巣Aが「3秒ごとに2」なら、2秒・3秒のそれぞれのタイミングで別々に減る。
  - 病巣が複数あれば、病巣ごとに別々のタイマーを持つ。治療が終わった病巣のタイマーは止まる。
- 一時停止中は、すべてのタイマーが止まる（[02_screens.md](02_screens.md)）。
- 最大値（99）を超えて回復しない。

### 1.3 麻酔

- 麻酔が効いている間は、拍動テンポが遅くなるとともに、バイタルの減少も緩やかになる。
- 効果時間と「減少を緩やかにする度合い」は、医療機器データ（麻酔薬）に基本値を持ち、係数で補正する（6章）。

| 項目 | 基本値の置き場所 | 基本値 |
|---|---|---|
| 効果時間 | 医療機器データ（麻酔薬） | TBD（例：10秒） |
| 減少の緩和率 | 医療機器データ（麻酔薬） | TBD（例：通常の 50%） |

### 1.4 ゲージの色

| バイタル | ゲージの色 | 拍動テンポ |
|---|---|---|
| 51〜99 | 緑 | 通常 |
| 26〜50 | 黄 | 早い |
| 1〜25 | 赤 | 危険域 |

- 麻酔が効いている間は、バイタルに関係なく拍動テンポが遅くなる。ゲージの色はバイタルに従う。
- テンポの表現は [04_surgery_area.md](04_surgery_area.md) 参照。

## 2. 制限時間

- ゲーム画面の右上に残り時間を表示する。
- 時間切れになったら、会話を表示したのちゲームオーバーにする。

## 3. クリア・ゲームオーバー条件

| 結果 | 条件 |
|---|---|
| クリア | 目的（クリア目標）を達成する |
| ゲームオーバー | バイタルが 0 になる、または制限時間が切れる（時間切れは会話を表示してからゲームオーバー） |

## 4. 目標

| 種類 | 内容 |
|---|---|
| クリア目標 | ステージをクリアするための条件。ブリーフィングで表示する |
| 努力目標 | ゲーム中に達成を目指す目標。ブリーフィングで表示し、達成すると高ランクになる |

## 5. 評価・ランク

- 手術結果に応じて点数で評価する。
- **加点方式**：点数の条件はステージデータに持たせ、条件を満たすと加点する。
- 具体的な条件と点数の計算方法は `TBD-03-3`。

| ランク | 点数 |
|---|---|
| XS | 100点 |
| S | 95点以上 |
| A | 80点以上 |
| B | 60点以上 |
| C | 40点以上 |
| D | 40点未満 |

- リトライしてもランクには影響しない（[02_screens.md](02_screens.md)）。

## 6. 係数による補正（ステージ補正・難易度）

### 6.1 考え方

- パラメータは**基本値**を1か所（医療機器データ、病巣データ、ステージデータ）に持ち、**係数**を掛けて実際の値を決める。
- 係数は2種類ある。

| 係数 | 置き場所 | 用途 | 初期値 |
|---|---|---|---|
| ステージ係数 | ステージデータ | そのステージ固有の補正（例：麻酔が効きにくい患者） | 1.0 |
| 難易度係数 | 難易度データ | プレイヤーが選んだ難易度による補正 | 1.0（標準の難易度） |

```
実際の値 ＝ 基本値 × ステージ係数 × 難易度係数
```

- 係数を指定しない項目は 1.0（補正なし）とする。
- バイタルなど整数で扱う値の端数処理は `TBD-03-7`。

### 6.2 係数を掛けられる項目（候補）

| 項目 | 基本値の置き場所 | 補足 |
|---|---|---|
| 麻酔の効果時間 | 医療機器データ | - |
| 麻酔の減少緩和率 | 医療機器データ | - |
| 自然減少（量・間隔） | ステージデータ | - |
| 病巣による減少（量・間隔） | 病巣データ | - |
| 治療ミスのダメージ | 医療機器データ、病巣データ | - |
| 治療成功・注射の回復量 | 病巣データ、医療機器データ | - |
| ストックやゲージの回復時間 | 医療機器データ | ヒールゼリー、注射 |
| 制限時間 | ステージデータ | - |
| 開始時のバイタル | ステージデータ | - |

- どの項目を係数の対象にするかの確定は `TBD-03-8`。

### 6.3 難易度

- **難易度はステージを選ぶときに、ステージごとに選ぶ**（[02_screens.md](02_screens.md) 3.2）。オプションなどで一律に設定する方式にはしない。
- 難易度ごとの係数は、難易度データにまとめて持つ。

| 難易度 | 係数の例（ダメージ・減少） | 係数の例（回復・効果時間・制限時間） |
|---|---|---|
| TBD（例：やさしい） | 0.7 | 1.3 |
| TBD（例：ふつう） | 1.0 | 1.0 |
| TBD（例：むずかしい） | 1.3 | 0.7 |

- 難易度の段階数と名前は `TBD-03-9`。
- リトライしても難易度は変わらない。
- 難易度が点数・ランクに影響するかは `TBD-03-10`。
- scenario.md のステージ3「手術難易度の分岐（結果は変わらない）」は、**この難易度とは別のもの**。会話の選択肢によって処置の内容が変わる分岐のこと（[01_overview.md](01_overview.md) 5.1、[07_data_format.md](07_data_format.md) 3.4）。
