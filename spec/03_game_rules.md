- 最終更新：2026-10-03

> **表記について**：数値は、決定した値と、例（決定ではない）を区別して書く。決定記録に無い規則を補うために推奨案を書いた箇所は **【仮案・未確認】** と明記し、対応する TBD を 7 章に置く。用語は [glossary.md](glossary.md) を参照（病巣、ステージデータ、病巣データ、医療機器データ、ストック、ゲージなど）。

## 1. バイタル

### 1.1 基本

| 項目 | 値 |
|---|---|
| 範囲 | 0〜99（単位：バイタル値） |
| 最大値 | 99 |
| 開始時の値 | ステージデータで指定する |
| ゲームオーバー | 0 になったとき |

### 1.2 増減

増減の量の単位はすべて「バイタル値」。

| 種類 | 内容 | 値 |
|---|---|---|
| 自然減少 | 一定時間ごとに下がる | 間隔と量を**ステージデータ**で指定する（例（決定ではない）：2秒ごとに1） |
| 病巣による減少 | 病巣があると一定時間ごとに下がる | 間隔と量を**病巣データ**で指定する（[06_lesions.md](06_lesions.md)） |
| 治療成功 | 手順の1段階が完了すると回復する | 病巣データに持つ（手順の段階ごと。[05_instruments.md](05_instruments.md) 2.1） |
| 失敗 | ダメージを受ける | 病巣データ（手順の段階ごと）の値。無ければ医療機器データの既定値（[07_data_format.md](07_data_format.md) 2.3） |
| 空振り | ダメージを受ける、または回復する、何も起きない（機器ごとに違う） | 医療機器データ（[05_instruments.md](05_instruments.md) 1.1） |
| ヒールゼリーを塗っている間の回復 | 塗っている間、成功・無効・空振りに関係なく回復する | 押した瞬間に1、以後2秒ごとに1、1回（ストック1回分）につき最大10（[05_instruments.md](05_instruments.md) 3.1） |
| 回復剤の注射 | 注入量に応じて回復する | 1回の最大注入で 20（仮の値。本家の値を調べる：`TBD-03-4`。「1回」の定義は [05_instruments.md](05_instruments.md) 3.6） |
| 薬の限度量の超過 | バイタルとは関係なくゲームオーバー | [05_instruments.md](05_instruments.md) 3.6、3章 |

- 「無効」の操作では、ダメージも回復も起きない（4分類は [07_data_format.md](07_data_format.md) 2.2）。無効のとき画面にメッセージは出さない（音は機器データ。[05_instruments.md](05_instruments.md) 3.1）。
- 自然減少と病巣による減少は、**それぞれ独立したタイマーで個別に（非同期で）判定・処理する**。
  - 例（決定ではない）：自然減少が「2秒ごとに1」、病巣Aが「3秒ごとに2」なら、2秒・3秒のそれぞれのタイミングで別々に減る。
  - 病巣が複数あれば、病巣ごとに別々のタイマーを持つ。治療が終わった病巣のタイマーは止まる。
- **タイマーの起点とリセット**（【仮案・未確認】、`TBD-03-15`）：
  - 各タイマーは、開始の時点（自然減少はステージ開始、病巣は出現の時点）から計り始め、**最初の減少は1間隔後**に起きる。
  - 自然減少のタイマーはステージ開始から連続して動き、ステップが変わってもリセットしない。
  - 一時停止で止まり、再開で続きから動く。
- 一時停止中は、ゲーム内の時間に関わるタイマーとアニメーションがすべて止まる（止める範囲は [02_screens.md](02_screens.md) 3.4）。
- 最大値（99）を超えて回復しない。

### 1.3 麻酔

- 麻酔が効いている間は、拍動テンポが遅くなるとともに、バイタルの減少も緩やかになる。
- 効果時間と「減少を緩やかにする度合い」は、医療機器データ（麻酔薬）に基本値を持ち、係数で補正する（6章）。
- **重ねがけできる**（残り時間に効果時間を足す）。そのかわり、患者ごとの限度量を超えて投与するとゲームオーバーになる（3章、[05_instruments.md](05_instruments.md) 3.6）。
- **緩やかにする対象と方法**（【仮案・未確認】、`TBD-03-13`）：自然減少と病巣による減少の**両方**を緩やかにする。実装は、減少の**間隔**を長くする（間隔 ＝ 基本の間隔 ÷ 緩和率。緩和率が 50% なら間隔は2倍）。失敗・空振りのダメージには効かない。
  - **理由**：間隔を変えれば、バイタルを整数のまま扱える（量に掛けると 0.5 のような端数が出る）。

| 項目 | 基本値の置き場所 | 基本値 |
|---|---|---|
| 効果時間 | 医療機器データ（麻酔薬） | 未定（例（決定ではない）：10秒。`TBD-03-6`） |
| 減少の緩和率 | 医療機器データ（麻酔薬） | 未定（例（決定ではない）：通常の 50%。`TBD-03-6`） |

### 1.4 ゲージの色

- ここでの「ゲージ」はバイタルを表示するバイタルゲージ。注射のゲージ（薬の残量）とは別物（[glossary.md](glossary.md)）。

| バイタル | ゲージの色 | 拍動テンポ |
|---|---|---|
| 51〜99 | 緑 | 通常 |
| 26〜50 | 黄 | 早い |
| 1〜25 | 赤 | 危険域 |

- 麻酔が効いている間は、バイタルに関係なく拍動テンポが遅くなる。ゲージの色はバイタルに従う。
- テンポの表現は [04_surgery_area.md](04_surgery_area.md) 参照。

## 2. 制限時間

- ゲーム画面の、医療機器の反対側の上端に残り時間を表示する（[02_screens.md](02_screens.md) 3.4）。
- 制限時間はステージデータで指定する（秒）。ステージ全体で1つ（ステップごとには分けない）。
- 時間切れになったら、会話を表示したのちゲームオーバーにする。

## 3. クリア・ゲームオーバー条件

| 結果 | 条件 |
|---|---|
| クリア | 目的（クリア目標）を達成する |
| ゲームオーバー | バイタルが 0 になる、制限時間が切れる（時間切れは会話を表示してからゲームオーバー）、または薬の投与量が患者ごとの限度量を超える（[05_instruments.md](05_instruments.md) 3.6） |

### 3.1 同時に成り立ったときの優先順位【仮案・未確認】（`TBD-03-14`）

同じ瞬間に複数の条件が成り立ったときは、次の順で判定する。

1. クリア（最後の病巣の治療が完了した）
2. バイタルが 0
3. 限度量の超過
4. 時間切れ

- 時間切れの会話を表示している間は、ゲーム内の時間を止める。会話の途中でバイタルが 0 になる、といったことは起きない。会話が終わったら必ずゲームオーバーにする。

### 3.2 トレーニングモード

トレーニングモード（[02_screens.md](02_screens.md) 3.7）のルール（決定、2026-10-03）。

| 項目 | 内容 |
|---|---|
| バイタル | あり。減少・回復・ダメージは本番と同じように働く。開始時の値・自然減少・ステージ係数・患者（限度量など）は**トレーニング用ステージ**（ステージデータの形。[07_data_format.md](07_data_format.md) 5.9）に持つ |
| 制限時間 | なし |
| ゲームオーバー | あり（バイタルが 0、薬の限度量の超過）。ゲームオーバーになったら病巣選択画面に戻る（[02_screens.md](02_screens.md) 3.7） |
| 終わり | 出した病巣（ランダムモードは決めた数）の治療が終わったら、リザルトへ（[02_screens.md](02_screens.md) 3.7） |
| 難易度 | ステージと同じ難易度係数を使う。病巣選択画面で切り替える（6.3） |
| 点数・評価 | 評価の扱いは再検討中（5.1、`TBD-03-16`）。リザルトとベスト記録は [02_screens.md](02_screens.md) 3.7 |

## 4. 目標

| 種類 | 内容 |
|---|---|
| クリア目標 | ステージをクリアするための条件。ブリーフィングで表示する。ステージデータに持つ（[07_data_format.md](07_data_format.md) 5.2） |
| 努力目標 | ゲーム中に達成を目指す目標。ブリーフィングで表示し、達成すると高ランクになる（5章の加点条件として持つ） |

## 5. 評価・ランク

- 手術結果に応じて点数で評価する。
- **加点方式**：点数の条件はステージデータに持たせ、条件を満たすと加点する。
- 具体的な条件と点数の計算方法は `TBD-03-3`。
- **点数の扱い**（【仮案・未確認】、`TBD-03-3`）：点数は整数。ステージデータの加点条件の合計が 100 点になるように作る。合計が 100 点を超える場合は 100 に丸める。
- ステージの評価（点数・ランク）と、病巣の治療の評価（5.1）を共通化するかは**再検討中**（`TBD-03-16`）。

| ランク | 点数 |
|---|---|
| XS | 100点（満点） |
| S | 95点以上 |
| A | 80点以上 |
| B | 60点以上 |
| C | 40点以上 |
| D | 40点未満 |

- リトライしてもランクには影響しない（[02_screens.md](02_screens.md) 3.5）。

### 5.1 治療の評価（Cool／Good／Fine／Bad）【再検討中】

> **【再検討中】**（`TBD-03-16`）：2026-10-03 にいったん下の内容で回答を受けたが、ステージの評価（5章の点数・ランク）と共通化したほうがよいとのことで、関連する内容をまとめて考え直すことになった。**この節は決定ではない**（前回の回答を参考として残している）。

- **病巣1つの治療が終わるごとに**、その治療を4段階で評価する（手順の段階ごとではない）。
- 段階の並び：**Cool ＞ Good ＞ Fine ＞ Bad**。
- 判定の条件（暫定）。条件（しきい値など）は**病巣データに持つ**（[07_data_format.md](07_data_format.md) 4章）。

| No | 条件 |
|---|---|
| 1 | 出現から解消（治療の完了）までの時間 |
| 2 | ミスが無い |
| 3 | 手順の省略をしない（例：切開の消毒＝ヒールゼリーを省略しない） |

- **失敗も評価に含める**。ただし、失敗したら即 Bad、にはしない。
- バッドテーピング（ヒールゼリーを省略してテーピングした。[05_instruments.md](05_instruments.md) 4章）の病巣は、必ず Bad（これは決定。ただし評価の再検討に合わせて見直す可能性あり）。
- 表示：病巣の近くに文字＋評価ごとの SE（[02_screens.md](02_screens.md) 3.4）。
- 点数との関係は未決（`TBD-03-16`）。医療機器の強調表示は評価・点数に影響しない（決定。評価の再検討に合わせて見直す可能性あり）。

## 6. 係数による補正（ステージ補正・難易度）

### 6.1 考え方

- パラメータは**基本値**を1か所（医療機器データ、病巣データ、ステージデータ）に持ち、**係数**を掛けて実際の値を決める。
- 係数は2種類ある。

| 係数 | 置き場所 | 用途 | 初期値 |
|---|---|---|---|
| ステージ係数 | ステージデータ | そのステージ固有の補正（例：麻酔が効きにくい患者） | 1.0 |
| 難易度係数 | システムデータ（難易度） | プレイヤーが選んだ難易度による補正 | 1.0（標準の難易度） |

```
実際の値 ＝ 基本値 × ステージ係数 × 難易度係数
```

- 係数を指定しない項目は 1.0（補正なし）とする。
- 係数は、他の上書き（医療機器 → 病巣 → 配置。[07_data_format.md](07_data_format.md) 2.4）が済んだ**最後**に掛ける。
- **係数の向き**（【仮案・未確認】、`TBD-03-12`）：係数は「その項目の効きの強さ（量・割合・速さ）」に掛ける。係数が大きいほど、ダメージや減少は大きく／速く、回復や効果時間や制限時間は大きく／長く／速くなる。このため、**時間・間隔で表す項目のうち「速さ」として効くものは、掛け算ではなく割り算にする**。

  | 演算 | 該当する項目 |
  |---|---|
  | 基本値 × 係数 | 量・大きさ・長さ：ダメージ、減少の量、回復量、麻酔の効果時間、制限時間、開始時のバイタル |
  | 基本値 ÷ 係数 | 間隔・かかる時間（短いほど効きが強い）：自然減少の間隔、病巣による減少の間隔、ストックの回復時間、注射のゲージの回復時間 |

- **端数の扱い**（【仮案・未確認】、`TBD-03-7`）：バイタルは内部では小数のまま持ち、表示とゲージの色の判定、ゲームオーバー（表示が 0 になったとき）は小数点以下を切り捨てた値で行う。回数など整数で扱う値（ストック数など）は係数の対象外とする。
- **ヒールゼリーの回復の上限**（【仮案・未確認】、`TBD-03-7`）：塗っている間の回復は、1回あたりの回復量と上限（基本値 10）の**両方**に同じ係数を掛ける。

#### 計算の例（数値はすべて例で、決定値ではない）

| 項目 | 基本値 | ステージ係数 | 難易度（例） | 実際の値 |
|---|---|---|---|---|
| 自然減少の間隔 | 2秒ごとに1 | 1.0 | やさしい（減少の係数 0.7） | 2 ÷ (1.0 × 0.7) ＝ 約2.86秒ごとに1 |
| メスの失敗ダメージ | 2 | 1.0 | むずかしい（ダメージの係数 1.3） | 2 × 1.0 × 1.3 ＝ 2.6（内部は小数。表示と判定は切り捨て） |
| 麻酔の効果時間 | 10秒（例） | 0.5（麻酔が効きにくい患者） | ふつう（1.0） | 10 × 0.5 × 1.0 ＝ 5秒 |

### 6.2 係数を掛けられる項目（候補。決定ではない）

「対象」は候補で、確定は `TBD-03-8`。【仮案・未確認】として、空間の大きさや回数など、掛けるとゲームの感覚が変わりすぎるものを「対象外」にしてある。

| 項目 | 基本値の置き場所 | 係数の対象（仮案） | 補足 |
|---|---|---|---|
| 麻酔の効果時間 | 医療機器データ | 対象（×） | 決定済み（効果時間は係数で補正する） |
| 麻酔の減少緩和率 | 医療機器データ | 対象（緩和率に ×） | - |
| 自然減少（間隔） | ステージデータ | 対象（÷） | - |
| 自然減少（量） | ステージデータ | 対象外（間隔のほうに掛ける。二重に掛けない） | - |
| 病巣による減少（間隔） | 病巣データ | 対象（÷） | - |
| 病巣による減少（量） | 病巣データ | 対象外（間隔のほうに掛ける） | - |
| 失敗・空振りのダメージ | 医療機器データ、病巣データ | 対象（×） | - |
| 治療成功・注射の回復量 | 病巣データ、医療機器データ | 対象（×） | ヒールゼリーの塗り回復は上限にも掛ける（6.1） |
| ストックやゲージの回復時間 | 医療機器データ | 対象（÷） | ヒールゼリーのストック、注射のゲージ |
| 制限時間 | ステージデータ | 対象（×） | - |
| 開始時のバイタル | ステージデータ | 対象外 | 0〜99 の範囲を保つため |
| 薬の限度量 | ステージデータ（患者） | 対象外 | 難易度でゲームオーバーの基準を変えない |
| 判定範囲・猶予幅・筆の半径・運び先の範囲 | 医療機器データ、病巣データ | 対象外 | 空間の大きさ。端末や難易度で操作感を変えない（[05_instruments.md](05_instruments.md) 3.4 も対象外で揃えてある。`TBD-03-8` で確定） |
| ストック数、ゲージの容量 | 医療機器データ | 対象外 | - |

### 6.3 難易度

- **難易度はステージを選ぶときに、ステージごとに選ぶ**（[02_screens.md](02_screens.md) 3.2）。オプションなどで一律に設定する方式にはしない。
- 難易度ごとの係数は、システムデータにまとめて持つ（[07_data_format.md](07_data_format.md) 6章）。実体は項目ごとの係数。下の表は、それを「ダメージ・減少」と「回復・効果時間・制限時間」の2グループにまとめて示した**例**。

| 難易度（名前も例） | 係数の例（ダメージ・減少） | 係数の例（回復・効果時間・制限時間） |
|---|---|---|
| やさしい（例） | 0.7 | 1.3 |
| ふつう（例） | 1.0 | 1.0 |
| むずかしい（例） | 1.3 | 0.7 |

- **この表の名前と数値はすべて例で、決定ではない**（`TBD-03-9`）。
- 難易度の段階数と名前は `TBD-03-9`。
- リトライしても難易度は変わらない。
- 難易度が点数・ランクに影響するかは `TBD-03-10`。
- シナリオ原稿のステージ3にある「手術難易度の分岐（結果は変わらない）」は、**この難易度とは別のもの**。会話の選択肢によって処置の内容が変わる分岐のこと（[01_overview.md](01_overview.md) 5.1、[07_data_format.md](07_data_format.md) 5.5）。
