## 記述ルール

1. 1ファイル1テーマ。H1 はファイルのタイトル、以下 H2／H3 で分ける。
2. 各ファイルの冒頭にステータス（草案／確定）と最終更新日を書く。
3. 数値パラメータは表にまとめ、単位（秒、マス、バイタル値、回）を必ず書く。
4. 決まっていないことは **`TBD-ファイル番号-連番`**（例：`TBD-03-02`）で示し、各ファイル末尾の「未決事項」にまとめる。
   - 見直し提案（[_records/2026-09-25_spec_review.md](../_records/2026-09-25_spec_review.md)）の ID（A1 など）があれば併記する。
5. 用語は [glossary.md](glossary.md) の定義に合わせる。
6. 画面遷移や手順の図は Mermaid で書く。
7. 仕様（何をするか）と理由（なぜそうするか）を分け、理由は「補足」として書く。

## 改訂方針

- 現在の版は memo.md の内容を**そのまま**移して整形したもの。内容の変更・追加はしていない（未決の点は TBD として明記した）。
- 未決事項が決まったら、該当ファイルに反映し、TBD を消して「最終更新」を更新する。
