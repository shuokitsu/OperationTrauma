## 1. 用語

### 1.1 ゲームの基本

| 用語 | 意味 | 関連 |
|---|---|---|
| 本家 | このゲームが参考にした「超執刀カドゥケウス」。仕様書は本家を知らなくても読めるように書く | [01](01_overview.md) |
| ステージ | 1回の手術（1人の患者、または1つのシナリオ上の場面）。会話 → ゲーム → リザルト → 会話で1セット。1つ以上のステップでできている | [01](01_overview.md)、[07](07_data_format.md) |
| ステップ | **ステージの中の手術の区切り**（例：切開 → 内臓）。ステージデータの配列の1要素。病巣の治療手順の1つ1つ（手順の段階）とは別 | [07](07_data_format.md) |
| 手順の段階 | **病巣の治療手順の1つ1つ**（例：裂傷の「ドレーン」「ピンセット」「縫合針」「ヒールゼリー」）。ステップとは別。単に「段階」とも書く | [05](05_instruments.md)、[06](06_lesions.md) |
| 治療手順 | 病巣を治療するときに医療機器を使う順番（手順の段階の並び） | [06](06_lesions.md) |
| バイタル | 患者の生命力を表す値（0〜99、単位：バイタル値）。無くなるとゲームオーバー | [03](03_game_rules.md) |
| バイタルゲージ | バイタルを表示するゲージ（画面上部）。色と拍動テンポがバイタルで変わる | [03](03_game_rules.md) |
| ダメージ | 失敗や空振りなどで、一度にバイタルが減ること。時間ごとに少しずつ減る「減少」（自然減少・病巣による減少）とは区別する | [03](03_game_rules.md) |
| ブリーフィング | ゲーム開始前に、病状・クリア目標・努力目標を確認する場面 | [02](02_screens.md) |
| クリア目標 | ステージをクリアするための条件 | [03](03_game_rules.md) |
| 努力目標 | 達成すると高ランクになる任意の目標 | [03](03_game_rules.md) |
| 評価 | 【再検討中】病巣の治療に付ける4段階の評価（Cool／Good／Fine／Bad）の案。ステージの点数・ランク（加点方式）との共通化を含めて再検討中 | [03](03_game_rules.md) 5.1 |
| トレーニングモード | タイトル画面から入る練習用のモード。ステージで治療したことのある病巣の種類を選んで（またはランダムに）治療する。制限時間なし、ゲームオーバーあり。値は専用のトレーニング用ステージ（ステージデータの形）に持つ | [02](02_screens.md) 3.7、[03](03_game_rules.md) 3.2 |
| リトライ | ゲーム画面をやり直すこと。ゲームオーバー画面とゲーム中のメニューから選べる。ランクに影響しない（コンティニューは無い） | [02](02_screens.md) |
| フラグ | 会話の選択肢の結果やステージのクリア状況を覚えておく印。シナリオ分岐や処置内容の分岐に使う | [02](02_screens.md)、[07](07_data_format.md) |
| 基本値 | 医療機器・病巣・ステージの各データに持つ、補正前のパラメータ値 | [03](03_game_rules.md) |
| ステージ係数 | ステージ固有の補正のために基本値に掛ける係数 | [03](03_game_rules.md) |
| 難易度 | ステージ選択時にステージごとに選ぶ難しさ。難易度係数で表す | [03](03_game_rules.md) |
| 難易度係数 | 選んだ難易度に応じて基本値に掛ける係数 | [03](03_game_rules.md) |
| 処置内容の分岐 | 会話の選択肢によって、同じステージの処置内容（病巣の構成・手順）が変わること。難易度とは別 | [07](07_data_format.md) |
| クランケ | 患者（ドイツ語由来の医療用語）。仕様書では基本的に「患者」と書く | - |
| 識別文字 | 病巣の種類につける識別用の文字（例：切り傷は a）。用途と形式は未定 | [06](06_lesions.md) |

### 1.2 画面・配置

| 用語 | 意味 | 関連 |
|---|---|---|
| 手術エリア | ゲーム画面中央の、手術を行う領域。マス目に分割する | [04](04_surgery_area.md) |
| 術野 | 手術エリアに表示される患部の範囲。ほぼ手術エリアと同じ範囲を指す。区別が要らない箇所では「手術エリア」と書く | [04](04_surgery_area.md) |
| マス | 手術エリアを分割した単位（横100×縦50。1マスは論理座標で 14×14） | [04](04_surgery_area.md) |
| マス座標 | 手術エリア内の位置を表す座標。横 0〜99、縦 0〜49、左上が [0, 0]。[x, y]（横, 縦）の順で書く | [04](04_surgery_area.md) |
| 論理座標 | 画面全体（1920×1080）の位置を表す座標。実際の画面の解像度とは関係なく決める。UI の配置に使う | [04](04_surgery_area.md) |
| 字幕エリア | ゲーム画面の下部の、映画の字幕のように会話が流れる領域。左に顔画像、右に字幕を置く。「リアルタイム会話ウィンドウ」と同じもの | [02](02_screens.md)、[04](04_surgery_area.md) |
| リアルタイム会話ウィンドウ | 字幕エリアの別名（02 での呼び名）。会話画面の会話ウィンドウとは別物 | [02](02_screens.md) |
| 顔画像 | 字幕エリアの左に表示する、話者の顔の画像。背景透過で、枠は付けない。会話画面の立ち絵とは別の素材 | [02](02_screens.md)、[08](08_assets.md) |
| 立ち絵 | 会話画面の左右に表示するキャラクターの全身（上半身）の絵 | [08](08_assets.md) |
| 空白エリア | ゲーム画面の、医療機器の反対側にある残り時間の下の領域（幅 260 × 高さ 890）。普段は何も置かず、ピンセットで物を掴んでいる間だけトレイを表示する。テーピングのテープもここに出す（どちらも枠外から出てくる演出つき） | [04](04_surgery_area.md)、[05](05_instruments.md) |
| メニュー | ゲーム画面で、医療機器の列の最上部のボタンから開く「リトライ」「タイトルに戻る」の選択。開いている間は一時停止する | [02](02_screens.md) |
| 強調表示 | 手術エリアに出ている病巣の今の段階で使うべき医療機器を、医療機器の列で点滅させて目立たせる表示。自動で決まり、オン・オフの設定は無い（チュートリアル用の強調表示は廃止） | [05](05_instruments.md) 2.8 |
| テンポ | 呼吸・拍動アニメーションの速さ。バイタルや麻酔で変わる | [04](04_surgery_area.md) |

### 1.3 医療機器・操作

| 用語 | 意味 | 関連 |
|---|---|---|
| 医療機器 | プレイヤーが手術に使う道具。6種類（ヒールゼリー、ドレーン、ピンセット、メス、縫合針、注射） | [05](05_instruments.md) |
| 特別機器 | 6つの医療機器とは別に持つ機器。医療機器の列には並べず、1〜6 キーにも入れない。今はテーピングだけ。値は医療機器データの「特別機器」の枠に持つ | [05](05_instruments.md) 4章 |
| テーピング | 特別機器の1つ。空白エリアに出てくるテープをタップで持ち上げ、傷の開始から終了までをスワイプして貼る。病巣データの治療手順の1段階として書く | [05](05_instruments.md) 4.1 |
| バッドテーピング | テーピングの前のヒールゼリーを省略してテーピングすること。テーピングは成功し、ダメージは無いが、評価は必ず Bad（評価の再検討に合わせて見直す可能性あり） | [05](05_instruments.md) 4.1 |
| ストック | ヒールゼリーを使える回数（5回。使うと1つ減り、一定時間で1つ回復する） | [05](05_instruments.md) |
| ゲージ | **注射の薬の残量**を表す量（使うと減り、時間で回復する）。バイタルを表示する「バイタルゲージ」とは別物 | [05](05_instruments.md) |
| 回復剤 | 注射で打てる薬の1つ。バイタルを回復する。「バイタル回復剤」と同じもの。どこに打っても効く | [05](05_instruments.md) |
| 筆の半径 | ヒールゼリーで塗る幅（半径 N マスの円） | [05](05_instruments.md) |
| トレイ | ピンセットで不要物を運ぶ先。掴んでいる間だけ、空白エリアに枠外から出てくる演出つきで表示する | [05](05_instruments.md) |
| 限度量 | 患者ごと・薬剤別に決める投与量の上限。累計で超えるとゲームオーバー | [05](05_instruments.md) |
| 量 | ドレーンで吸い出す対象（血溜まり・膿など）の量。病巣データが、量・時間による自然増・最大値を持つ。バイタルの値とは別の単位 | [05](05_instruments.md)、[07](07_data_format.md) |
| 自然増 | 病巣の「量」が、時間とともに自然に増えること（出血のようなイメージ）。バイタルの「自然減少」とは別 | [05](05_instruments.md)、[07](07_data_format.md) |
| 小さな切り傷 | メスの空振りで、切った場所に発生する病巣。ヒールゼリーだけで治る。治さないとステップを終えられない（ステップ完了条件に含む）。形は切った軌跡から作る（長さ上限は例10マス） | [05](05_instruments.md)、[06](06_lesions.md) |

### 1.4 病巣・判定

| 用語 | 意味 | 関連 |
|---|---|---|
| 病巣 | 手術エリアに現れる治療対象（傷、破片、腫瘍など。物も病巣の一種として扱う） | [06](06_lesions.md) |
| 判定データ | 病巣が持つ、治療の成否を判定するための**形**の総称。マス座標で持ち、見た目（画像）とは別。次の2種類がある | [04](04_surgery_area.md) |
| ヒットエリア | 判定データのうち、**範囲**で持つもの（押す、塗る、吸う、掴む、などの判定に使う）。病巣側が持ち、医療機器側には持たない | [04](04_surgery_area.md)、[05](05_instruments.md) |
| 通過点 | 判定データのうち、**点のリスト**で持つもの（メスの切開線、縫合針の縫う線）。メスは順番どおりにすべて通過すれば成功、縫合針は通過点を繋いだ線を通過点の数以上またいで指を離せば成功（通過点の数は最低ノルマ。5つなら5回またぐ＝2往復半） | [05](05_instruments.md) |
| 判定範囲 | 通過点のまわりの円。操作の位置がこの円に入れば、その通過点を通過したとみなす（例（決定ではない）：2マス以内）。運び先（ピンセット）の判定の範囲にも同じ言葉を使う | [05](05_instruments.md) |
| 猶予幅 | 通過点どうしを結んだ直線から、操作の軌跡が外れてもよい幅（例（決定ではない）：3マス） | [05](05_instruments.md) |
| 手順違い | 病巣の上で、その病巣の今の段階と違う機器を使うこと。結果は機器ごとに決める | [05](05_instruments.md) |
| 成功 | 操作の結果の1つ。**治療手順の1段階が完了した** | [07](07_data_format.md) |
| 失敗 | 操作の結果の1つ。**病巣に対して操作したが、やり方を誤った**（ダメージ） | [07](07_data_format.md) |
| 無効 | 操作の結果の1つ。**操作したが何も起きない**（ダメージも無い） | [07](07_data_format.md) |
| 空振り | 操作の結果の1つ。**病巣の無い場所を操作した**。その機器にとって対象にならない病巣の上の操作も、空振りとして扱う場合がある。結果（ダメージ・回復・何も起きない）は医療機器ごとに決める | [07](07_data_format.md)、[05](05_instruments.md) |

### 1.5 データ

| 用語 | 意味 | 関連 |
|---|---|---|
| 医療機器データ | 道具そのものの性能を持つデータ。どの病巣・どのステージでも同じ値（ストック数、筆の半径、空振りの結果、失敗の既定値など） | [07](07_data_format.md) |
| 病巣データ | 病巣の種類ごとの「ひな形」のデータ。その種類ならどこに出ても同じ値（見た目、判定データ、治療手順、回復値、ダメージ値、SE など） | [07](07_data_format.md) |
| ステージデータ | 1回の手術の状況を持つデータ。その場面だけの値（開始バイタル、制限時間、ステップの配列、病巣の配置など） | [07](07_data_format.md) |
| 処置データ | ステップの中で、そのステップの処置を表すまとまり。病巣の配置の並びと、処置中の会話を持つ | [07](07_data_format.md) |
| システムデータ | ゲーム全体の調整用の値（今は難易度ごとの係数）。項目が多くなれば専用ファイルに分ける | [07](07_data_format.md) |
| 病巣の種類・配置 | 種類は病巣データに持つひな形（見た目・手順・回復値など）。配置はステージデータに持つ「どの種類を・どこに・いつ出すか」 | [07](07_data_format.md) |

### 1.6 仕様書の表記

| 用語 | 意味 | 関連 |
|---|---|---|
| TBD | 決まっていないこと。`TBD-ファイル番号-連番` で示し、各ファイル末尾の「未決事項」にまとめる | [README](README.md) |
| 【仮案・未確認】 | 決定記録に無い規則を補うために書いた推奨案。ユーザーの確認が済むまで決定ではない | [README](README.md) |
| 提案ID | A1、R1、M1 などの番号。_records の提案書で、決定の経緯をたどるための印。本文の理解には不要 | [README](README.md) |
| ギルス系 | 本家の用語。手術エリアの中を動く特殊な病巣（敵のようなもの）。名称の採否はユーザーが決める（`TBD-04-5`） | [04](04_surgery_area.md) |

## 2. 表記ゆれ

仕様書では左の表記にそろえる。

| 統一表記 | ゆれ | 出典・補足 |
|---|---|---|
| 病巣 | 症状、患部、処置対象 | memo.md。「処置対象」は総称の案（`TBD-06-1`） |
| ヒールゼリー | ビールゼリー | scenario.md（誤記と思われる） |
| 医療機器 | 治療器具、機器、道具 | フォルダ名の「治療器具パラメータ」は「医療機器データ」に直した（08）。「機器」は文脈が明らかなときの略 |
| 治療手順 | 治療順 | 病巣を治療する機器の順番。その1つ1つは「手順の段階」 |
| 手順の段階 | 段階 | 病巣の治療手順の1つ。ステージ内の区切りの「ステップ」と区別する |
| ステップ | （ステージ内の区切りの意味では他の語を使わない） | - |
| 筆の半径 | 筆の大きさ | ヒールゼリー |
| 字幕エリア | リアルタイム会話ウィンドウ、字幕ウィンドウ | 同じもの。会話画面の「会話ウィンドウ」とは別物 |
| 立ち絵 | キャラ絵、キャラクター絵、表示イラスト | 会話画面のキャラクターの絵（08 では「キャラ」） |
| 顔画像 | 顔グラ | 字幕エリアの話者の顔 |
| 空白エリア | 空間、空き領域 | 医療機器の反対側の領域 |
| 回復剤 | バイタル回復剤、回復薬 | 注射の薬 |
| ゲージ（注射） / バイタルゲージ | ゲージ | 単に「ゲージ」と書くときは注射の薬の残量。バイタルは「バイタルゲージ」と書く |
| 判定データ / ヒットエリア / 通過点 / 判定範囲 | 判定の範囲 | 「判定データ」は総称、ヒットエリアは範囲型、通過点は点のリスト型、判定範囲は通過点のまわりの円。範囲型の意味で「判定の範囲」と書かない |
| 処置 / 治療 | 手術 | 「処置データ」はステップの中の病巣の配置などのまとまり。「治療」はプレイヤーが機器で病巣に対して行う操作や手順 |
| ダメージ / 減少 | バイタル減少 | ダメージは一度に減ること、減少は時間ごとに減ること（自然減少・病巣による減少） |
