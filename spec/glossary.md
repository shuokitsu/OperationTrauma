# 用語集

- ステータス：草案
- 最終更新：2026-09-26

## 1. 用語

| 用語 | 意味 | 関連 |
|---|---|---|
| バイタル | 患者の生命力を表す値。無くなるとゲームオーバー | [03](03_game_rules.md) |
| 病巣 | 手術エリアに現れる治療対象（傷、破片、腫瘍など） | [06](06_lesions.md) |
| 治療順 | 病巣を治療するときの医療機器を使う順番 | [06](06_lesions.md) |
| 医療機器 | プレイヤーが手術に使う道具。6種類 | [05](05_instruments.md) |
| 手術エリア | ゲーム画面中央の、手術を行う領域。マス目に分割する | [04](04_surgery_area.md) |
| 術野 | 手術エリアに表示される患部の範囲 | [04](04_surgery_area.md) |
| マス | 手術エリアを分割した単位 | [04](04_surgery_area.md) |
| ヒットエリア | 病巣側が持つ判定の範囲（病巣の判定データ）。医療機器側には持たない | [04](04_surgery_area.md)、[05](05_instruments.md) |
| 筆の大きさ | ヒールゼリーで塗る幅（半径 N マスの円） | [05](05_instruments.md) |
| 手順違い | 病巣の上で、その病巣の今の段階と違う機器を使うこと。結果は機器ごとに決める | [05](05_instruments.md) |
| トレイ | ピンセットで不要物を運ぶ先。掴んでいる間だけ、医療機器の反対側の空白エリアに表示する | [05](05_instruments.md) |
| 限度量 | 患者ごと・薬剤別に決める投与量の上限。累計で超えるとゲームオーバー | [05](05_instruments.md) |
| クランケ | 患者 | - |
| ステップ | ステージ内の手術の段階（例：切開 → 内臓） | [07](07_data_format.md) |
| ブリーフィング | ゲーム開始前に、病状・クリア目標・努力目標を確認する場面 | [02](02_screens.md) |
| クリア目標 | ステージをクリアするための条件 | [03](03_game_rules.md) |
| 努力目標 | 達成すると高ランクになる任意の目標 | [03](03_game_rules.md) |
| リアルタイム会話ウィンドウ | ゲーム中、画面下部に字幕のように流れる会話 | [02](02_screens.md) |
| 強調表示 | 特定の医療機器を目立たせる表示（チュートリアル用） | [07](07_data_format.md) |
| リトライ | ゲーム画面の開始時点からやり直すこと。ゲームオーバー画面とゲーム中のメニューから選べる。ランクに影響しない（コンティニューは無い） | [02](02_screens.md) |
| 基本値 | 医療機器・病巣・ステージの各データに持つ、補正前のパラメータ値 | [03](03_game_rules.md) |
| システムデータ | ゲーム全体の調整用の値（今は難易度ごとの係数）。項目が多くなれば専用ファイルに分ける | [07](07_data_format.md) |
| 病巣の種類・配置 | 種類は病巣データに持つひな形（見た目・手順・回復値など）。配置はステージデータに持つ「どの種類を・どこに・いつ出すか」 | [07](07_data_format.md) |
| 成功・失敗・無効・空振り | 操作の結果の4分類。成功＝手順の1段階が完了、失敗＝病巣への操作を誤った、無効＝何も起きない（ダメージも無い）、空振り＝病巣の無い場所を操作した（その機器にとって対象にならない病巣の上も含む場合がある） | [07](07_data_format.md) |
| ステージ係数 | ステージ固有の補正のために基本値に掛ける係数 | [03](03_game_rules.md) |
| 難易度 | ステージ選択時にステージごとに選ぶ難しさ。難易度係数で表す | [03](03_game_rules.md) |
| 処置内容の分岐 | 会話の選択肢によって、同じステージの処置内容（病巣の構成・手順）が変わること。難易度とは別 | [07](07_data_format.md) |
| 難易度係数 | 選んだ難易度に応じて基本値に掛ける係数 | [03](03_game_rules.md) |
| 判定データ | 病巣の治療の成否を判定するための形。マス座標で持つ。見た目（画像）とは別 | [04](04_surgery_area.md) |
| 通過点 | メスの切開線や縫合針の縫う線を表す判定データの座標。メスは順番どおりにすべて通過すれば成功、縫合針は通過点を繋いだ線を通過点の数だけまたげば成功 | [05](05_instruments.md) |
| 判定範囲 | 操作の位置が通過点を通過したとみなす範囲（例：2マス以内。円で測る） | [05](05_instruments.md) |
| 猶予幅 | 通過点どうしを結んだ直線から、操作の軌跡が外れてもよい幅（例：3マス） | [05](05_instruments.md) |
| テンポ | 呼吸・拍動アニメーションの速さ。バイタルや麻酔で変わる | [04](04_surgery_area.md) |
| ギルス系 | 本家の用語。術野を動く特殊な病巣。名称の採否はユーザーが決める（`TBD-04-5`） | [04](04_surgery_area.md) |
