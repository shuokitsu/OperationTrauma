## 1. フォルダ構成

```
（ゲーム）
├── ゲーム
│   ├── プログラム
│   └── データ
│       ├── 病巣データ
│       ├── 治療器具パラメータ
│       └── 難易度データ
├── 画像
│   ├── キャラ
│   └── 背景
├── サウンド
│   ├── SE
│   └── BGM
└── シナリオ
    └── テキスト
```

## 3. 素材

### 3.1 画像

| 種類 | 内容 | 補足 |
|---|---|---|
| キャラ | 会話画面の左右に表示するイラスト | - |
| 背景（会話） | 会話画面の背景 | - |
| 背景（手術） | 患者の画像 | 呼吸・拍動アニメーションのため最低3枚（[04_surgery_area.md](04_surgery_area.md)） |

### 3.2 サウンド

| 種類 | 内容 |
|---|---|
| SE | 効果音 |
| BGM | 音楽 |
| ボイス | 音声（[07_data_format.md](07_data_format.md) のシナリオデータで指定。フォルダは `TBD-08-2`） |
