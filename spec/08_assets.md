# 08 フォルダ構成・素材

- ステータス：草案
- 最終更新：2026-10-03

## 1. フォルダ構成

```
（ゲーム）
├── ゲーム
│   ├── プログラム
│   └── データ
│       ├── 病巣データ
│       ├── 医療機器データ
│       ├── ステージデータ（【仮案・未確認】。置き場所は TBD-08-5）
│       └── システムデータ（難易度など。項目が多くなれば専用ファイルに分ける）
├── 画像
│   ├── キャラ（立ち絵・顔画像）
│   └── 背景
├── サウンド
│   ├── SE
│   └── BGM
└── シナリオ
    └── テキスト
```

- データの中身は [07_data_format.md](07_data_format.md) 参照。各データの意味は [glossary.md](glossary.md)。
- 「医療機器データ」は、以前の名称「治療器具パラメータ」を、用語の統一（glossary の表記ゆれ）に合わせて改めたもの。
- 実際のフォルダ名（英語表記など）は `TBD-08-1`。

## 3. 素材

### 3.1 画像

| 種類 | 内容 | 補足 |
|---|---|---|
| 立ち絵（キャラ） | 会話画面の左右と、ゲーム画面のキャラクター絵つきの会話（[02_screens.md](02_screens.md) 3.4）に表示するキャラクターの絵 | - |
| 顔画像 | ゲーム画面の字幕エリアの左に表示する話者の顔。**背景透過**、画像を囲む枠は付けない、人物の輪郭は表示する | 立ち絵とは別素材として用意する案（【仮案・未確認】、`TBD-08-4`）。表示サイズは未決定（[04_surgery_area.md](04_surgery_area.md) 1.3、`TBD-04-7`） |
| 背景（会話） | 会話画面の背景 | - |
| 背景（手術） | 患者の画像 | 呼吸・拍動アニメーションのため最低3枚（[04_surgery_area.md](04_surgery_area.md)）。外傷は普通の人物絵、体内は青を基調とした記号的な表現 |
| 医療機器アイコン | 医療機器の列に並べる6種類（ヒールゼリー、ドレーン、ピンセット、メス、縫合針、注射）。選択中の表示と、強調表示（通常の色・薄い色の点滅。[05_instruments.md](05_instruments.md) 2.8）も必要 | 注射を選んだときに横に並べる薬ボタン（回復剤、麻酔、特定の病巣用の薬）の画像も必要（[05_instruments.md](05_instruments.md) 3.6） |
| 病巣の見た目 | 病巣の種類ごとの画像（切り傷、裂傷、破片痕、腫瘍、切開、小さな切り傷など） | 判定データ（形）とは別に持つ（[04_surgery_area.md](04_surgery_area.md) 2章）。血溜まり・膿など状態の変化の見た目も必要 |
| トレイ | ピンセットで物を掴んでいる間だけ空白エリアに表示する受け皿の画像。枠外から出てくる演出に使う | [05_instruments.md](05_instruments.md) 3.3 |
| テープ（特別機器） | テーピングで空白エリアに出すテープと、貼った後の画像。バッドテーピング専用の見た目は作らない | [05_instruments.md](05_instruments.md) 4.1 |
| 治療の評価の文字【再検討中】 | Cool／Good／Fine／Bad の文字（病巣の近くに表示する案。評価は再検討中） | [03_game_rules.md](03_game_rules.md) 5.1 |
| UI（バイタルゲージ、メニュー、ボタンなど） | ゲーム画面とメニューの部品 | 具体的な一覧は `TBD-08-3` |

### 3.2 サウンド

| 種類 | 内容 |
|---|---|
| SE | 効果音（医療機器の操作中の音、操作の結果の音、病巣の発生・段階の完了・治療の完了の音、治療の評価ごとの音（評価は再検討中）など。[05_instruments.md](05_instruments.md) 2.6、[03_game_rules.md](03_game_rules.md) 5.1） |
| BGM | 音楽 |
| ボイス | 音声（[07_data_format.md](07_data_format.md) のシナリオデータで指定。フォルダは `TBD-08-2`） |
