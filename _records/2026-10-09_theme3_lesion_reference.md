# 参考資料：病巣を考えるための部品の一覧（テーマ3「病巣の再整理」用）

- 作成：2026-10-09
- 種類：**参考資料**（たたき台・提案ではない。決定も含まない）
- 根拠：仕様書 `spec/`（2026-10-09 時点）。仕様書と食い違ったときは仕様書を正とする。

## 1. はじめに

- **目的**：テーマ3「病巣の再整理」で、ユーザーが病巣（傷・腫瘍・破片など、治療する対象）を考え直すときの手元資料。今の仕様で「何が使えるか」「何がまだ決まっていないか」を1か所にまとめた。
- **この資料は決定ではない**。新しい病巣の案や、どれがよいかの推奨は書いていない。病巣の中身を決めるのはユーザー。
- **使い方**：
  1. 2章で、病巣を組み立てる部品（形・機器・データに持てる値）を眺める。
  2. 3章で、今ある病巣が部品の組み合わせでどうできているかを見る。
  3. 考えた病巣が「部品の組み合わせで作れるか」「新しい仕組みが要るか」を4章で見分ける。
  4. 5章のテンプレートを病巣ごとにコピーして埋める。
  5. 6章で、テーマ3で決める予定のことの抜けが無いか確かめる。
- **表の「状態」列の見方**

| 印 | 意味 |
|---|---|
| 決定 | 仕様書で決定として書かれている |
| 例 | 説明用の値。決定ではない |
| 仮案 | 仕様書で【仮案・未確認】と書かれている |
| 未決 | TBD（未決事項）。番号を付けた |

## 2. 病巣を組み立てる「部品」の一覧

### 2.1 ヒットエリアの形（判定データ）

- **判定データ**＝病巣が持つ「当たり判定の形」。画面に見える絵（見た目）とは別に持つ（[04 2章](../spec/04_surgery_area.md)）。
- 判定データには2種類ある。**ヒットエリア**（範囲。押す・塗る・吸う・掴むに使う）と、**通過点**（順番付きの点のリスト。メス・縫合針に使う）。
- 座標は手術エリアのマス（横100×縦50）で書く。形は病巣の種類が持ち、位置はステージの配置で決める。データの座標は配置の位置を [0, 0] とした**相対座標**（決定、[04 2章](../spec/04_surgery_area.md)）。

| 部品 | 書き方の例 | 向いている見た目の例（仕様書の例から） | 状態 |
|---|---|---|---|
| 円 | 中心と半径（例：半径2マス） | 大きさのある点（腫瘍、血溜まりなど） | 決定 |
| 太さのある線 | 折れ線の点のリストと太さ（線から何マス以内か） | 細長い傷（切り傷、裂傷） | 決定 |
| マスの集まり | マスを1つずつ並べる | 不規則な形、四角い形、1マスの小さな点（破片痕） | 決定 |
| 組み合わせ | 上の図形を複数並べると、その合わせた範囲がヒットエリアになる | 円と線がつながった形など | 決定 |
| 通過点（線状） | 端のある点のリスト（例：`[0,0]` `[5,5]` `[10,10]`） | 切開線、縫う線 | 決定 |
| 通過点（円形） | 閉じた点のリスト（一周する） | 腫瘍の周りを切る線 | 決定 |

- 四角の図形は「使う見通しが無い」ため外した。必要になったら図形の種類を増やす（＝プログラムの追加）（決定、[04 2章](../spec/04_surgery_area.md)）。
- メスの通過点には**作るときの決まり**がある：隣り合う点は判定範囲の直径（例：4マス）より離す、隣の隣の点と判定範囲を重ねない、曲がり角で点を内側に寄せすぎない（決定。数値は例、[07 4章](../spec/07_data_format.md)、[05 3.4](../spec/05_instruments.md)）。
- 参考：スマートフォンでは1マスが約0.9mm と小さく、細かい形は操作しにくいという課題が出ている（試作 v03 の P78。保留中）。

### 2.2 医療機器 6つ＋テーピングで「できる処置」

- 用語：**成功**＝手順の1段階が完了／**失敗**＝やり方を誤った（ダメージ）／**無効**＝何も起きない（ダメージも無し）／**空振り**＝病巣の無い場所を操作した（[07 2.2](../spec/07_data_format.md)）。
- **手順違い**＝今の段階と違う機器を病巣に使うこと。結果は機器ごとに違う（[05 2.2](../spec/05_instruments.md)）。
- くわしくは [05 1.1 早見表](../spec/05_instruments.md) と各機器の節。

| 機器 | 病巣の段階として使える処置 | 判定のしかた | 成功 | 失敗 | 無効（手順違いを含む） | 空振り | 病巣データ側で決める値 |
|---|---|---|---|---|---|---|---|
| ヒールゼリー（[3.1](../spec/05_instruments.md)） | 軽い傷の治療、消毒、生理食塩水の代わり、縫ったあとの癒着 | 筆でなぞった範囲が、ヒットエリアのマスの何割を覆ったか | しきい値（例：80%）以上覆った。覆いきらない分は点数を減点 | なし | しきい値に足りない、手順違い、ストック0、血溜まり・膿が重なっている | 塗っている間の回復だけ起きる | 成功時の回復値、しきい値の上書き、覆いきらない分の減点 |
| ドレーン（[3.2](../spec/05_instruments.md)） | 血溜まり・膿を吸い出す（物を吸えるかは病巣ごとに決める） | 押している位置がヒットエリア内の間、量が減る（0.1秒あたり1） | 量が0になった | なし | 吸う物が無い病巣の上 | 何も起きない | 量・自然増・最大値 |
| ピンセット（[3.3](../spec/05_instruments.md)） | 物を動かす（取り出してトレイへ、決まった位置へ動かす）、裂傷の傷口を寄せる | 掴む位置がヒットエリア内か、離した位置が運び先か | 運び先で離した | 運び先以外で離した（物は元の位置へ戻る） | 掴めない物の上（手順違い） | 何も起きない | 運び先（トレイ／既定の位置と範囲）、失敗のダメージ |
| メス（[3.4](../spec/05_instruments.md)） | 切開、線を切る、周りを一周切る | 通過点を順番どおりに通るか、線から猶予幅を外れないか | 最後の通過点に着いた | 猶予幅を外れた、端以外から切り始めた、点を飛ばした、手順違い（ダメージ 既定2） | 全部通る前に離した（やり直せる） | ダメージ2＋**小さな切り傷**が発生 | 通過点、失敗のダメージ。判定範囲・猶予幅は機器で固定（病巣で変えない） |
| 縫合針（[3.5](../spec/05_instruments.md)） | 傷や切開を縫う | 通過点を繋いだ線をまたいだ回数（場所・順番は問わない） | 離した時点で、またいだ回数が通過点の数以上 | 線から猶予幅の外に出た（ダメージ 既定1） | 離した時点で回数が足りない | ダメージ1（縫う段階ではない病巣の上も） | 通過点（点の数＝必要な回数）、失敗のダメージ |
| 注射（[3.6](../spec/05_instruments.md)） | 特定の病巣用の薬を打つ（回復剤・麻酔は病巣の段階ではなく、どこでも効く） | 押した位置が対象の病巣のヒットエリア内か。押している間ゲージを使って注入 | 必要量を入れた | 薬による（手順違いでダメージになる薬もある） | ゲージ0、薬によっては手順違い | 特定の病巣用の薬：ダメージ1、注入しない | 使う薬、必要量 |
| テーピング（特別機器、[4.1](../spec/05_instruments.md)） | 傷をテープで留めて治療を終える | テープ（幅およそ7マスの帯、押した点と離した点を結ぶ）で傷のマスを何割覆えたか | 3割以上覆えた。はみ出た分は減点 | なし | 3割に足りない | （定めなし） | 段階として手順に入れる。省略の減点（バッドテーピング） |

補足（どれも決定）：

- 血溜まり・膿が重なっている病巣は、吸い切るまで**ドレーン以外すべて無効**（[06 1章](../spec/06_lesions.md)）。
- 体を傷つける機器（メス・縫合針）だけ、手順違いがダメージになる。それ以外は無効（[05 2.2](../spec/05_instruments.md)）。
- 1回の操作（押して離すまで）の結果は1つ。分類は押した位置で決まる（ヒールゼリーだけは複数の病巣を一度に塗れる）（[05 2.1](../spec/05_instruments.md)）。

| 決まった位置へ動かす物（血管など）と、特定の病巣用の薬が、最初のゴールで要るか | `TBD-05-13` |

### 2.3 病巣データに持てる値

病巣データ（病巣の「ひな形」）に持てる値。出典は [07 4章](../spec/07_data_format.md)、[06 1章](../spec/06_lesions.md)、[03 5.1](../spec/03_game_rules.md)。

| 項目 | 内容 | 状態 |
|---|---|---|
| 見た目 | 手順の段階ごとの画像と、治療が終わった後の画像（例：異物を取ったら、取った後の傷が見える） | 決定（2026-10-09） |
| 音 | 発生・段階の完了・治療の完了の音。段階ごとに指定できる | 決定 |
| 判定データ | ヒットエリア（2.1）と、メス・縫合針用の通過点 | 形式は決定、病巣ごとの形は未決（`TBD-06-8`） |
| 治療手順 | 機器を使う順番（手順の段階の並び）。テーピングも1段階として書ける | 決定 |
| 省略できる段階 | 飛ばしてもよい段階（例：切開の前の消毒）。省略したときのダメージ（次の段階が成功した時点で与える）と、点数の減点を持つ。省略はミスに数えない | 決定 |
| 成功時の回復値 | 段階ごと | 項目は決定、値は未決（`TBD-06-8`） |
| 失敗時のダメージ値 | 段階ごと。無ければ機器の既定値 | 項目は決定、値は未決（`TBD-06-8`） |
| 失敗したときの扱い | 最初の段階に戻るか、戻らないか。戻るのは結果が「失敗」のときだけ。戻すのは段階だけで、血溜まりの量などは戻さない | 仕組みは決定、どの病巣が戻るかは未決（`TBD-06-8`） |
| バイタルの減少 | 病巣があるあいだ、何秒ごとにいくつ減るか。病巣ごとに別のタイマー。治療が終われば止まる | 項目は決定、値は未決（`TBD-06-8`） |
| 吸い出す量 | 血溜まり・膿の量、時間による自然増、最大値 | 項目は決定、値は未決（`TBD-06-8`） |
| 時間による変化 | 例：裂傷の再出血。「量が自然増で0から再び増える」として扱い、別の仕組みは作らない | 決定（秒数は `TBD-06-8`） |
| 運び先 | ピンセットで運ぶ先（トレイ、または既定の位置と範囲）。ステージの配置で上書きできる | 決定 |
| 他の治療を妨げる状態 | 血溜まり・膿が重なっている病巣はドレーン以外無効 | 決定 |
| 点数・評価の条件 | 100点満点。時間（早いほど多い）・ミスが無い・省略しない に配点し、失敗・省略・覆いきらない分を減点。値は病巣ごとに持つ。時間のしきい値には難易度が掛かる | 仕組みは決定、配点は例（試して調整） |

**病巣どうしの重なり**（決定、[06 1章](../spec/06_lesions.md)、[05 2.1](../spec/05_instruments.md)）

| 種類 | 扱い |
|---|---|
| ふつうの病巣どうし | 重ならない |
| 血溜まり・膿 | **独立した病巣**（手順はドレーンだけ）として配置する。ほかの病巣やほかの血溜まりに重なってよい。量に応じて広がる。重なった血溜まりは同時に吸える |
| 小さな切り傷（メスの空振りで発生） | ほかの病巣と重ねて出す |
| 重なった場所を押したとき | ① 血溜まり・膿が重なる病巣はドレーン以外無効 → ② 今の段階に合う病巣を優先 → ③ あとから出た病巣を優先 |

## 3. 今ある病巣の分解

[06 2章](../spec/06_lesions.md) の病巣を、2章の部品に分けたもの。「判定データ」は spec でも**暫定**。

| 病巣 | ヒットエリア（暫定） | 通過点 | 治療手順（段階 → 使う機器） | 特徴 |
|---|---|---|---|---|
| 切り傷 | 太さのある線 | なし | ① ヒールゼリー | 1段階だけの軽い傷 |
| 裂傷 | 太さのある線 | 線状（縫合針用） | ① ドレーン（重なる血溜まりを吸い切る）→ ② ピンセット（開いた傷口を寄せる）→ ③ 縫合針 → ④ ヒールゼリー（癒着） | 血溜まりは独立した病巣として重ねる。再出血あり（量の自然増）。② の操作のしかたは未決（`TBD-06-8`） |
| 破片痕 | マスの集まり（1マス）または小さな円 | なし | ① ピンセット（トレイへ運ぶ）→ ② ヒールゼリー | 「物」を取り除く病巣 |
| 腫瘍 | マスの集まりまたは円（ドレーン・ゼリー用） | 円形（メス用。周りを切る） | **未決**（`TBD-06-2`）。決まっているのは「膿を吸わないと治療できない（ドレーン）」「摘出前にヒールゼリーを生理食塩水の代わりに使う」だけ | 膿が重なる |
| 切開 | 太さのある線（消毒用） | 線状（メス用） | ① ヒールゼリー（**省略可**）→ ② メス | 省略するとメス成功時にダメージ1（ミスに数えない、点数は減点） |
| 小さな切り傷 | 切った軌跡の折れ線から1マス以内 | なし | ① ヒールゼリー | メスの空振りで実行中に発生。ステージに配置を書かない。バイタル減少なし。治さないとステップが終わらない。点数には数えない |
| 血溜まり（独立した病巣） | 円など（量に応じて広がる。広がり方は未決） | なし | ① ドレーン | ほかの病巣に重なってよい。重なっている病巣はドレーン以外無効 |
| 膿（独立した病巣） | 同上 | なし | ① ドレーン | 同上 |

- 「物」（破片・ごみ・異物・血管など、ピンセットで動かす物）も病巣の一種。種類の一覧はテーマ3で作る（`TBD-06-8`、`TBD-06-6`）。
- 参考：テーピングで終わる手順の書き方の例（縫合針 → ヒールゼリー（省略可）→ テーピング）が [07 4.1](../spec/07_data_format.md) にある（説明用の例で、病巣の種類としては決まっていない）。

## 4. 「組み合わせで作れる病巣」と「新しい仕組みが要る病巣」の見分け方

- 病巣データは**プログラム側**のデータ。今ある部品の組み合わせなら、データを足すだけで新しい病巣を作れる。部品に無い動きは、プログラムの追加が要る（決定、[07 1.1](../spec/07_data_format.md)）。
- プログラムの追加が要る病巣は、作る手間が増え、本実装の前に部品として決めておく必要がある。

### 4.1 判断の目安

次の問いに**すべて「はい」**なら、組み合わせで作れる見込みが高い。1つでも「いいえ」なら、新しい仕組みが要る可能性がある。

| No | 問い | 「いいえ」のときに要るもの |
|---|---|---|
| 1 | 形は、円・太さのある線・マスの集まり（とその組み合わせ）、通過点で書けるか | 新しい図形の種類 |
| 2 | 使う機器は6つの機器とテーピングだけで、操作のしかたも今のままか | 新しい機器・新しい操作方法 |
| 3 | 治療手順は「決まった順番に1段階ずつ進む」（省略できる段階があってもよい）で書けるか | 手順の分岐・順番自由などの仕組み |
| 4 | 時間で変わるのは「量が自然増で増える」だけか | 時間で動く・形が変わるなどの仕組み |
| 5 | 病巣は自分のことだけで完結するか（重なりの決まりは今のとおりでよいか） | 病巣どうしの連動の仕組み |
| 6 | 結果（成功・失敗・無効・空振り）の決まりは今の機器のとおりでよいか | 新しい結果の決まり |
| 7 | 見た目の変化は「段階ごとの画像の差し替え」で足りるか | 段階の途中で見た目を変える仕組み |
| 8 | 値（回復・ダメージ・減少・点数）は病巣データの項目（2.3）で表せるか | 新しい項目 |

### 4.2 仕組みの追加が要りそうな典型的な要素（一般論）

| 要素 | どういうものか | 今の仕様で近いもの |
|---|---|---|
| 時間で動く | 病巣が手術エリアの中を移動する | 無い（動く特殊な病巣は `TBD-04-5` で別に扱う予定） |
| 時間で増える・広がる | 病巣が分かれる、別の病巣を生む、形が大きくなる | 量の自然増と、量に応じた血溜まりの広がり（広がり方は未決） |
| 時間で悪化する | 放っておくと別の状態・段階に変わる、減少が強まる | 再出血（量の自然増として扱う）のみ |
| 複数の病巣が連動する | Aを治すとBが変わる、Aが残っているとBが悪化する | 血溜まり・膿が重なる病巣を止める決まり。ほかの病巣の完了後に出す「出現条件」はステージ側の部品（`TBD-07-2`） |
| 新しい操作方法 | 2本指、長押しの長さ、回す、叩く回数など | 無い（指は1本だけ扱う。[05 2.5](../spec/05_instruments.md)） |
| 手順の分岐 | 順番を選べる、やり方が2通りある | 「省略できる段階」のみ |
| 段階で形が変わる | 処置の途中でヒットエリアが変わる | 書かれていない（2.4 の Q1） |
| 見えない・隠れている | 探さないと分からない病巣 | 無い（探す機器は省略した。[05 1章](../spec/05_instruments.md)） |
| 新しい種類の薬・機器 | 6つの機器に無い効果 | 特定の病巣用の薬（要るかは `TBD-05-13`） |
| 状態で値が変わる | 量や残り時間でダメージ・減少が変わる | 無い（減少は間隔と量が一定） |

- 上の表は、見分けるための例。どれを入れるか・入れないかは決めていない。
