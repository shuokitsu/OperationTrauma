# たたき台：医療機器の再整理（手順2）

- 作成日：2026-09-26
- 目的：医療機器ごとに「操作方法・判定方法・成功・失敗・無効・空振り」を同じ形の表で整理し、決まっていない点を決める（`TBD-05-10` の手順2）
- 前提：[spec/07_data_format.md](../spec/07_data_format.md) 2章のルール（R1〜R7 で決定）
  - 空振り → 医療機器データ、成功 → 病巣データ、失敗 → 病巣データ（無ければ医療機器データの既定値）、無効 → 値なし
- 扱う課題：P5〜P7、P9、P12〜P20（[prototype_findings](2026-09-25_prototype_findings.md)）、D5、E1〜E5（[spec_review](2026-09-25_spec_review.md)）、TBD-05-*、TBD-07-6
- ステータス：**たたき台（ユーザーの回答待ち）**
- 回答の書き方：各表の「回答・決定」列（✅ 決定済み／🔶 一部決定・検討中／⬜ 未回答）

### この資料で決めないこと

| 内容 | 決める場所 |
|---|---|
| 回復量・ダメージ量・秒数などの**具体的な数値** | テーマ4（バランス）。この資料の数値は「例」 |
| 病巣ごとの手順・判定データ（裂傷の「ピンセット」の意味 P8、血溜まりで止める機器 P10 など） | テーマ3（病巣の再整理） |
| ミスで発生した病巣を治さないとクリアできないか（P30） | テーマ6（データ・進行） |

## 1. 全体の一覧

| 機器 | 操作方法 | 判定方法 | 成功 | 失敗 | 無効 | 空振り |
|---|---|---|---|---|---|---|
| ヒールゼリー | 押してなぞる（塗る） | ヒットエリアをすべて覆ったか | 覆った | なし | 覆いきれない、手順違い | 回復（2秒ごとに1、1回最大10） |
| ドレーン | 押し続ける | 吸い口が血溜まり・膿に重なっているか | 吸い切った | なし | 吸う物が無い病巣の上 | 何も起きない |
| ピンセット | 掴んでドラッグ | 掴む位置、運び先 | 運び終えた | 運ぶ途中で離した | 掴めない物、手順違い | 何も起きない |
| メス | 1回でなぞる（切る） | 通過点と猶予幅 | 全通過点を通った | 猶予幅を外れた、手順違い | 途中で離した、線の途中から切り始めた | ダメージ＋病巣の発生 |
| 縫合針 | 線をまたぐようにジグザグに縫う | 通過点を繋いだ線をまたいだ回数 | 通過点の数だけまたいだ | 手順違い（ほかは M28） | 前の段階が終わっていない | ダメージ |
| 注射 | 押している間注入（案） | 薬の種類による | 注入した | なし | ゲージ0、対象違いの薬 | 薬による |

- 「手順違い」：病巣の上で、その病巣の今の段階と違う機器を使うこと（2章 M2）。
- 「空振り」：手術エリアの中で、病巣の無い場所を操作すること（2章 M3）。

## 3. 機器ごとの表

### 3.1 ヒールゼリー

| 項目 | 内容（案） |
|---|---|
| 用途 | 軽い傷の治療（癒着）、切開前の消毒、摘出前の生理食塩水の代わり、縫合後の癒着 |
| 操作方法 | 押して、なぞって塗る。指を離すまでが1回。**押した時点でストックを1消費する** |
| 判定方法 | 筆（半径 N マスの円）でなぞった範囲を記録する。指を離した時点で、病巣のヒットエリアを**すべて**覆っていれば成功（M8）。1回で複数の病巣を塗れば、病巣ごとに判定する（まとめて治療できる） |
| 成功 | 病巣の手順が1段進む。回復は病巣データの回復値（無ければ既定値 1） |
| 失敗 | なし |
| 無効 | 覆った割合が足りない（やり直せる）、手順違い、ストックが0 |
| 空振り | **回復する**（M9）。塗っている間、2秒ごとに1回復、1回（ストック1回分）で最大10（M11） |
| 医療機器データに持つ値 | ストック数（5）、ストックの回復時間（M29 で確認）、筆の半径、塗っている間の回復（2秒ごとに1）、1回あたりの回復の上限（10）、成功時の既定の回復値 |

| ID | 課題 | 案（推奨） | 他の案 | 回答・決定 | 反映先 |
|---|---|---|---|---|---|
| M9 | 空振りのときの回復（E4、P2、TBD-05-1） | **回復しない**。回復は病巣に塗って成功したときだけにする。理由：何も無い場所に塗り続けるだけで、自然減少をほぼ打ち消せてしまうため | 回復1のまま（今の仕様）、1回の手術で回復できる回数に上限を設ける | ✅ 案は不採用。**空振りでも回復する**。病巣によるダメージ（減少）もあるため、高い難易度で必要になる想定。ステージごとの上限も設けない（ストック数とストックの回復時間が事実上の上限になる）。回復のしかたは M11 | spec/05 |
| M10 | 「全体を覆った」の判定（P14、TBD-05-10） | 病巣の判定マスを **一定の割合（例：80%）以上**覆えば成功。割合と筆の半径は医療機器データに持つ（値はテーマ4）。理由：100% だと、面の広い病巣で何度も往復が必要になり、ストックが足りなくなる | 100%（今の仕様の文言どおり）、病巣データで割合を上書きできるようにする | ✅ M8 で決定：**ヒットエリアをすべて覆えば成功**（割合の案は不採用。100% で確定）。筆の半径はテーマ4 | spec/05 |
| M11 | ストックを消費するタイミング | **押した時点で消費する**（無効でも消費する）。理由：何も考えずに塗り続けることを防ぐ | 成功したときだけ消費する | 🔶 採用（押した時点で消費）。あわせて**ストック1回分あたりの回復量に上限を設ける**：塗っている間、**2秒ごとに1回復、最大10**まで（最大の効果を得るには20秒塗り続ける必要がある）。「3秒から2秒に変更」の対象の確認 → M29 | spec/05 |

| 項目 | 内容（案） |
|---|---|
| 用途 | 血溜まり・膿の吸い出し |
| 操作方法 | 押し続ける。押したまま動かせる |

| 成功 | 量が0になったら、病巣の手順が1段進む |

| 空振り | 何も起きない |
| 医療機器データに持つ値 | 吸い出し速度（0.1秒あたり 1）（吸い口の大きさは M27 の回答による） |

| ID | 課題 | 案（推奨） | 他の案 | 回答・決定 | 反映先 |
|---|---|---|---|---|---|
| M12 | 吸い出し速度の決め方（E5、TBD-05-4） | **医療機器データに「1秒に吸える量」、病巣データに「血溜まり・膿の量」を持つ**。大きい血溜まりほど時間がかかる。理由：R4 のルール（道具の性能は医療機器、病巣ごとの違いは病巣）に合う | 1秒で全体の一定割合を吸う（大きさに関係なく同じ秒数で吸い切る） | ✅ 採用。**吸える量は 0.1秒あたり 1**（医療機器データ）。病巣データには、量に加えて**時間による自然増**（出血のようなイメージ）と**最大値**を持つ（病巣ごとの中身はテーマ3） | spec/05、06、07 4章 |

| 無効 | 掴めない物の上（手順違いを含む） |
| 空振り | 何も起きない |

### 3.4 メス

| 項目 | 内容（案） |
|---|---|
| 用途 | 切開、（将来）動く病巣への攻撃（`TBD-04-5`） |
| 操作方法 | 1回のスワイプ／ドラッグでなぞって切る |
| 判定方法 | 通過点の案（spec/05 3.4）：通過点の判定範囲（例：2マス）、点どうしを結んだ線からの猶予幅（例：3マス） |
| 成功 | 最後の通過点に着いた時点で成功（指を離す必要はない） |
| 失敗 | 猶予幅を外れた、手順違い（ダメージは病巣データ、無ければ既定値 2）。外れた時点でその操作は終わる |
| 無効 | すべての通過点を通る前に離した（やり直せる）、始点以外から切り始めた（M18） |
| 空振り | ダメージ（既定値 2）＋病巣の発生（M17） |
| 医療機器データに持つ値 | 判定範囲、猶予幅、失敗の既定ダメージ、空振りの結果（ダメージ、発生させる病巣の種類）、「切った」とみなす最短の長さ |

| ID | 課題 | 案（推奨） | 他の案 | 回答・決定 | 反映先 |
|---|---|---|---|---|---|
| M17 | 空振りで発生する病巣（P7） | **ダメージ＋小さな切り傷（ヒールゼリーだけで治る病巣）を、切った場所に発生させる**。ほかの病巣と重なる場所には発生させない（ダメージだけ）。軌跡が短い（例：2マス未満）ときは切ったとみなさず、何も起きない（タップだけで病巣が出ないようにする）。理由：今の仕様（裂傷）は4段階の処置が必要で重すぎる | ダメージだけ、裂傷のまま（今の仕様） | ⬜ 未回答 | - |
| M18 | 切り始める位置（P5、TBD-05-6） | **どちらの端の通過点からでも切り始めてよい**。端以外（線の途中）から始めた場合は無効（ダメージなし）とする | 決まった端からだけ、途中からでもよい | 🔶 M8 で一部決定：**線状は端から開始しないと NG**。残り：どちらの端からでもよいか、NG は「失敗（ダメージ）」か「無効」か（→ M28 と一緒に確認） | spec/05 |
| M19 | 閉じた線（腫瘍の周り）の切り方（P6） | **どの通過点から始めてもよく、向きも自由**。すべての点を通って始めた点に戻れば成功 | 決まった点から、決まった向きだけ | ✅ M8 で決定：**円形はどこから開始してもよい**。向きは自由（案のとおり。違えば指摘してください） | spec/05 |
| M20 | 距離の測り方（TBD-05-6） | **円（まっすぐな距離）で測る**。理由：斜めになぞっても、縦横になぞっても同じ感覚になる | 正方形（縦横それぞれのマス数）で測る | ⬜ 未回答 | - |

### 3.5 縫合針

| 項目 | 内容（案） |
|---|---|
| 用途 | 裂傷の縫合、切開した箇所の縫合 |
| 操作方法 | **通過点を繋いだ線をまたぐように、ジグザグに縫う**（M8、M21） |
| 判定方法 | 判定データとして通過点の座標を持つ（メスと同じ形）。通過点を繋いだ線を、操作の軌跡がまたいだ回数を数える |
| 成功 | 通過点の数だけまたいだ時点で、病巣の手順が1段進む（例：通過点3個なら3回） |
| 失敗 | 手順違い（縫う必要の無い病巣を縫った）。ほかに何を失敗にするかは M28。ダメージは病巣データ、無ければ既定値 1 |
| 無効 | 前の段階が終わっていない（例：血溜まりが残っている）。M2 では縫合針の手順違いは失敗としているが、この場合だけ無効にする（M22） |
| 空振り | ダメージ（既定値 1） |
| 医療機器データに持つ値 | 失敗の既定ダメージ、空振りのダメージ、（M28 で決まれば）線からの猶予幅など |

### 3.6 注射

| 項目 | 内容（案） |
|---|---|
| 用途 | バイタル回復剤、麻酔、その他の治療薬・特効薬 |
| 操作方法 | 手術エリアを**押している間、ゲージを消費して注入する**（離すと止まる）（M23） |
| 判定方法 | 回復剤・麻酔：手術エリアのどこに打ってもよい。特定の病巣に打つ薬：ヒットエリア（3×3）が病巣に重なっているか（M24） |
| 成功 | 注入量に比例した効果（回復剤は回復、麻酔は効果時間）。特定の病巣に打つ薬は、必要量を入れると病巣の手順が1段進む |
| 失敗 | なし |
