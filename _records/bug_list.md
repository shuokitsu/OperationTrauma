# 不具合の一覧（本実装のテスト対象）

- 試作で見つかった不具合をためておく一覧。**本実装のときは、この一覧をテスト項目として使う**（2026-10-03 ユーザー指示）。仕様が変わって当てはまらなくなったものは、その旨を書いて対象から外す。
- ユーザーから報告されたもの（報告）と、エージェントが試作を作りながら見つけたもの（試作中）を分けて書く。
- 新しい不具合が見つかったら、下の表に番号を足して追記する（番号は使い回さない）。
