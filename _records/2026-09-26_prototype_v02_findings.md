| ヒールゼリー（M9〜M11、M29） | 押した瞬間に1回復し、以後2秒ごとに1。18秒で10に達し、その後は回復しない。ストックは押した時点で消費し、5秒で1回分戻る。覆いきれないと無効。血溜まりのある傷は無効 |

| 縫合針（M21、M22、M28、M31、M33、M34） | 1回のスワイプで、線をまたいだ回数が通過点の数に達すると成功。同じ場所の往復でもよい。途中で離すと回数が0に戻り無効。縫う段階ではない病巣・何も無い場所は空振り（ダメージ1） |
| 注射（M23〜M26、M32、M35） | 押している間注入。薬ボタンで切り替え、持ち替えても最後の薬を覚える。開始直後は回復剤。特定の病巣用の薬は、空振り・対象外の病巣でダメージ1（注入しない）。麻酔は重ねがけ。投与量が限度量の70%で警告、超えた瞬間にゲームオーバー |
| 共通（M3〜M8） | 最初の1本の指だけ扱う。スワイプ中は持ち替えられない。手術エリアの外の操作は何も起きない。空振り・失敗・無効の音は機器ごとにデータで持つ |

## 4. 技術面で分かったこと（参考）

- 医療機器ごとの操作を「押す → 動かす → 離す」の1つの形（クラス）にまとめると、M1〜M35 の成功・失敗・無効・空振りをそのまま書けた。
- 「その機器にとって対象にならない病巣は空振りとして扱う」（M33）は、判定の順番（対象の病巣 → ほかの病巣 → 何も無い場所）を決めれば無理なく実装できた。
- 距離を円で測る（M20）、線をまたいだ回数を数える（M28）は、どちらも線分の計算だけで実装できた。頂点ちょうどをまたいだときに2回数えない工夫が必要だった。
- 画面の拡大縮小の直後にクリックすると、古い倍率で座標を変換することがあった（試験中に一度だけ）。本実装では、画面サイズが変わったときの処理の順番に注意する。
