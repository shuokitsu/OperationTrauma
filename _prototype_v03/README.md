## 起動方法

### GitHub Pages（スマホでの確認向け）

リポジトリの Settings → Pages で `main` ブランチの `/ (root)` を公開すると、次の URL で開ける（ルートの `.nojekyll` で `_` 始まりのフォルダも公開される）。

- https://shuokitsu.github.io/OperationTrauma/_prototype_v03/

### ローカル

データを `fetch` で読むため、`index.html` を直接開くと動かない。プロジェクトのルート（OperationTrauma）で次を実行し、http://localhost:8125/_prototype_v03/ を開く。

```bash
python -m http.server 8125
```

## 操作

| 操作 | 内容 |
|---|---|
| クリック／タップ・ドラッグ | 手術エリアで選択中の医療機器を使う（最初の1本の指だけ扱う） |
| 医療機器アイコン、1〜6 キー | 医療機器の持ち替え（押している間は持ち替えられない） |
| 6 キー（注射を選んでいるとき） | 薬ボタンを開く／閉じる。薬はクリックで選ぶ |
| 空白エリアのテープ | タップして持ち上げ、傷の端から端へなぞる（テーピング） |
| Menu、Esc | メニュー（再開／リトライ／タイトルに戻る） |
| H | 病巣の上に、今使う機器の名前を出す（試作用） |
| G | マス目の表示（試作用） |

ステージセレクトは、ステージのつながり（クリアで開放されるステージ、分岐を含む）を線で結んだフローチャート。

タイトル画面の「オプション」は、試作 v02 と同じ形（タイトル画面の上にパネルを重ねる。医療機器の配置、SE 音量、BGM 音量、文字送り速度、会話画面全スキップ）。

タイトル画面の「試作：全ステージ開放」「試作：セーブ消去」、トレーニングの「試作：全病巣を練習可能に」は確認用。

## ステージ

| ステージ | 内容 | 確かめる仕様 |
|---|---|---|
| ステージ1 | scenario.md の会話。擦り傷 → 破片 →（コンティニューポイント）→ 裂傷と重なった血溜まり2つ → 回復剤 → 切開（消毒は省略可）と異物 → 縫合・ゼリー・テーピング | ヒールゼリーの8割判定、トレイ、血溜まりの同時吸引と重なりの無効、省略の減点、バッドテーピング |
| ステージ2（仮） | 患者A（裂傷）→（コンティニューポイント）→ 止める会話・患者Bに差し替え → 麻酔（限度量 少なめ）→ 腫瘍と膿 →（コンティニューポイント）→ 閉じる | 患者の差し替え、限度量のゲームオーバー、円形のメス、膿が重なった病巣の無効 |
| ステージ3（仮） | ゲーム前の選択肢で処置内容が変わる（腫瘍2つ／腫瘍1つ＋感染巣） | 処置内容の分岐、分岐ごとの開始位置、特定の病巣用の薬（抗菌剤） |
| ステージ4（仮） | 時間差で出血が増える。途中の止める会話の選択肢で闇落ち／光落ちが開放される | 同時多発（時間差の出現）、ゲーム中の選択肢 |
| 闇落ち／光落ち（仮） | クリアでエンディングの会話 | エンディング |
| トレーニング | クリアしたステージに出た病巣を1つずつ練習（指定／ランダム5つ）。難易度の切り替えを常に表示、制限時間なし | トレーニングモード、ベスト記録 |

ステージ1の会話は scenario.md の原稿のまま。ゲーム内の字幕だけ、新しい仕様に合わせて一部の文言を変えた（「掴んで画面外に出す」→「掴んでトレイに運ぶ」など。試作のためで、原稿の書き換えの採否はユーザーが決める）。

## 構成

| パス | 内容 |
|---|---|
| `src/core.js` | 画面の拡大縮小と入力（範囲外のタッチは無視、中断は「離した」扱い）、音、セーブ、描画の部品 |
| `src/geometry.js` | マス座標の計算（距離は円で測る、ヒットエリアは円・線・マスの集まり） |
| `src/lesion.js` | 病巣（種類＋配置、血溜まり・膿は独立した病巣）、病巣の点数（100点満点）と評価 |
| `src/surgery.js` | ゲーム画面（医療機器ごとの操作と判定、重なりの扱い、終了条件の優先順位、コンティニューポイント、トレーニング） |
| `src/screens.js` | タイトル、ステージセレクト（難易度）、会話・ブリーフィング、開始位置の選択、リザルト、ゲームオーバー、トレーニングの画面 |
| `src/main.js` | 起動、画面の切り替え、セーブとの橋渡し |
| `data/` | プログラム側：医療機器・病巣・システム（難易度）。内容側：ステージ・会話。値はすべて仮 |
| `assets/`、`tools/` | 仮素材と生成スクリプト（v02 からコピー）。2026-10-09 に、仕様にあってまだ無かった音（心電図、評価、テーピングなど SE 14個、BGM 2曲）を `tools/gen_sounds.py` に足した（ゲームからはまだ使っていない）。一覧と試聴は `tools/sound_list.html`（ローカルなら http://localhost:8125/_prototype_v03/tools/sound_list.html ） |
