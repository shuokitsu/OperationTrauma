## 起動方法

プロジェクトのルート（OperationTrauma）で次を実行し、ブラウザで http://localhost:8124 を開く。

```bash
python -m http.server 8124 --directory _prototype_v02
```

## 操作

| 操作 | 内容 |
|---|---|
| クリック／タップ・ドラッグ | 手術エリアで選択中の医療機器を使う（最初の1本の指だけ扱う） |
| 医療機器アイコン、1〜6 キー | 医療機器の持ち替え（操作中は持ち替えられない） |
| 注射の横の薬ボタン | 薬の切り替え（回復剤／麻酔／抗菌剤） |
| Menu、Esc | メニュー（一時停止） |
| H | 病巣の上の「次に使う機器」表示の切り替え（試作用） |
| G | マス目表示の切り替え（試作用） |

## ステージ

| ステージ | 内容 | 確かめる仕様 |
|---|---|---|
| ステージ1 | scenario.md の会話とゲーム内テキスト。擦り傷 → 破片 → 裂傷 → 皮膚の中の異物 | ゼリー、ピンセット（トレイ）、ドレーン、ジグザグ縫合、線状のメス、消毒の省略、回復剤 |
| ステージ2（仮） | 開腹 → 血管を寄せる → 腫瘍 → 閉腹 | 麻酔と限度量、既定の位置への移動、円形のメス、ステップ切り替え |
| ステージ3（仮） | 選択肢で腫瘍の数が変わる | 処置内容の分岐、特定の病巣用の薬（抗菌剤） |
| ステージ4（仮） | 選択肢で闇落ち／光落ちが開放される | シナリオ分岐、複数の病巣の同時発生 |
| 闇落ち／光落ち（仮） | クリアでエンディングの会話 | エンディング |

## 構成

| パス | 内容 |
|---|---|
| `src/core/` | 画面の拡大縮小と入力、音、セーブ、UI 部品 |
| `src/game/geometry.js` | マス座標の計算（距離は円で測る） |
| `src/game/lesion.js` | 病巣（種類＋配置、手順の段階） |
| `src/game/tools.js` | 医療機器ごとの操作と判定（spec/05 3章） |
| `src/scenes/surgery.js` | ゲーム画面 |
| `src/scenes/screens.js` | タイトル、ステージセレクト、会話、リザルト、ゲームオーバー |
| `data/` | 医療機器・病巣・ステージ・会話・システム（難易度）のデータ。値は仮 |
| `assets/`、`tools/` | 仮素材と生成スクリプト（v01 からコピー） |
