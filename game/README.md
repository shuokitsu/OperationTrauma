# OperationTrauma 正式版

`spec/` の仕様から作った正式版です（試作 `_prototype_vNN/` のプログラムは使っていません。仮素材の画像・音だけを引き継いでいます）。

## 遊び方

- GitHub Pages：https://shuokitsu.github.io/OperationTrauma/game/
- ローカル：リポジトリのルートで下のコマンドを実行し、http://localhost:8130 を開く。

```bash
python -m http.server 8130 --directory game
```

- 確認用の機能（セーブ消去、全ステージ開放、マス目の表示など）は、URL の最後に `?debug=1` を付けると出ます（[data/README.md](data/README.md) 3章）。

## フォルダ

| フォルダ | 内容 |
|---|---|
| `src/` | プログラム |
| `data/` | データ（機器・病巣・ステージ・会話）。**書き方は [data/README.md](data/README.md)**。書き換えて再読み込みすれば反映される |
| `assets/images/`、`assets/sound/` | 画像と音（すべて仮素材） |
| `tools/` | 仮素材を作ったスクリプト |

| プログラム | 内容 |
|---|---|
| `src/main.js` | 起動、画面の拡大縮小、入力、データの読み込みと点検 |
| `src/screens.js` | タイトル、オプション、ステージセレクト、リザルト、ゲームオーバー、トレーニング、エンディング、ステージの進行 |
| `src/talk.js` | 会話（会話画面、治療を止める会話、暗転、選択肢） |
| `src/surgery.js` | ゲーム画面（バイタル、時間、ステップ、字幕、心電図、画面の描画） |
| `src/tools.js` | 医療機器の操作と判定 |
| `src/lesion.js`、`src/draw.js` | 病巣の動きと点数、病巣・操作ガイドの描画 |
| `src/geometry.js`、`src/ui.js`、`src/assets.js`、`src/save.js` | 座標計算、画面の部品、素材と音、セーブ |

## 今の状態（2026-11-15）

- ステージ1・2 は scenario.md のとおり。ステージ4 は scenario.md に書かれている範囲のとおり。
- ステージ3 のゲーム画面の中身、ステージ5・6 の全部は、scenario.md が作成中のため**仮の内容**（各ファイルの先頭の `_note`）。
- 数値（ダメージ、回復、時間、配点、難易度の係数など）は、仕様で決まっているもの以外は**仮の値**。
- 病巣の見た目は図形で描いている（画像の素材ができたら差し替える）。顔画像は立ち絵の上の部分で代用。
- まだ入れていないもの：マイクロマシン（仕様が検討中）、限度量の警告メッセージ、ボイス。
