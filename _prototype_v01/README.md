## 起動方法

プロジェクトのルート（OperationTrauma）で次を実行し、ブラウザで http://localhost:8123 を開く。

```bash
python -m http.server 8123 --directory _prototype_v01
```

## 操作

| 操作 | 内容 |
|---|---|
| クリック／タップ・ドラッグ | 手術エリアで選択中の医療機器を使う |
| 医療機器アイコン、1〜6 キー | 医療機器の切り替え（注射をもう一度選ぶと薬を切り替え） |
| Menu、Esc | メニュー（一時停止） |
| H | 次に使う機器のヒント表示の切り替え（試作用） |
| G | マス目表示の切り替え（試作用） |

## 構成

| パス | 内容 |
|---|---|
| `src/core/` | 画面の拡大縮小、入力、音、セーブ、UI 部品 |
| `src/scenes/` | 各画面（タイトル、ステージセレクト、会話、手術、リザルト、ゲームオーバー） |
| `src/game/` | マス座標、病巣 |
| `data/` | 医療機器・病巣・難易度・ステージのデータ（値はすべて仮） |
| `assets/` | 仮の画像（SVG）・サウンド（WAV）。再利用できるよう生成スクリプトを `tools/` に置いた |
| `tools/gen_images.py`、`tools/gen_sounds.py` | 仮素材の生成スクリプト（標準ライブラリのみ） |
