## 操作

| 操作 | 内容 |
|---|---|
| クリック／タップ・ドラッグ | 手術エリアで選択中の医療機器を使う（最初の1本の指だけ扱う） |
| 医療機器アイコン、1〜6 キー | 医療機器の持ち替え（押している間は持ち替えられない） |
| 注射のアイコン、6 キー | 注射を選ぶと薬ボタンが開く。もう一度押すと閉じる。薬はボタンで選ぶ |
| 空白エリアのテープ | テープの上で押して離すと持ち上がる。手術エリアで押した点と離した点を結ぶ帯として貼る。持ち上げると、選択中の機器はテープ扱いになり、機器の列は6つとも未選択の表示になる。持ち上げ中にテープの場所をもう一度押すと置き、持ち上げる前の機器に戻る |
| Menu、Esc | メニュー（再開／リトライ／タイトルに戻る）。トレーニングでは（再開／病巣選択に戻る） |
| H | 病巣の下に、今使う機器の名前を出す（試作用） |
| G | マス目の表示（試作用） |

タイトル画面の「試作：全ステージ開放」「試作：セーブ消去」、トレーニングの「試作：全病巣を練習可能に」は確認用。

## 動作確認の方法（エージェント向け）

- ブラウザのプレビューが非表示だと画面の更新が止まるので、`app.step(秒)` を直接呼んで進める。入力は `app.input.events` に `{type:'down'|'move'|'up', x, y}`（論理座標）を積む。
- ファイルを変えたら、`fetch('src/….js', {cache:'reload'})` で読み直してから再読み込みする（古いスクリプトが使い回されるため）。
- ステージの途中から試すときは `app.beginSurgery({ stage, difficulty, flags: {} }, ステップの番号)`。止める会話は、画面の中央を押す入力を積んで進める。
- 病巣データの書き方（2026-10-11 に追加。試作の仮）：`points`（病巣の点）、段階ごとの `path`（その段階で使う線）・`tap`（ピンセットでタップする点）・`connect`（ピンセットで繋ぐ2点）・`spawn_on_success`（成功したときに出す病巣）、`with`（一緒に出す病巣）、`bleed`（時間で血溜まりを出す）。字幕のきっかけに `lesion_step`（病巣が N 番目の段階に進んだ。0から数える）と `lesion_unblocked`（重なった血溜まりが無くなった）を足した。
