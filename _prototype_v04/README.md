## 操作

| 操作 | 内容 |
|---|---|
| クリック／タップ・ドラッグ | 手術エリアで選択中の医療機器を使う（最初の1本の指だけ扱う） |
| 医療機器アイコン、1〜6 キー | 医療機器の持ち替え（押している間は持ち替えられない） |
| 注射のアイコン、6 キー | 注射を選ぶと薬ボタンが開く。もう一度押すと閉じる。薬はボタンで選ぶ |
| 空白エリアのテープ | テープの上で押して離すと持ち上がる。手術エリアで押した点と離した点を結ぶ帯として貼る。持ち上げ中にテープの場所をもう一度押すと置く |
| Menu、Esc | メニュー（再開／リトライ／タイトルに戻る）。トレーニングでは（再開／病巣選択に戻る） |
| H | 病巣の下に、今使う機器の名前を出す（試作用） |
| G | マス目の表示（試作用） |

タイトル画面の「試作：全ステージ開放」「試作：セーブ消去」、トレーニングの「試作：全病巣を練習可能に」は確認用。

## v04 で新しく確かめられること

| 仕様 | 内容 |
|---|---|
| 心電図（spec/03 1.4） | バイタルゲージの後ろに心電図を流し、拍ごとに「ピッ」。バイタルが下がるほど拍が早くなる（99 で 1分に60拍 → 1 で 150拍。値は仮）。麻酔中はバイタルによらずゆっくり（48拍）、効き始め・切れ目は約3秒かけて移る。患者画像の拍動も同じテンポ |
| 心電図の平坦 | バイタル0と限度量の超過で平坦（赤い線）になり「ピー」が鳴り続ける。時間切れでは平坦にしない |
| ゲームオーバーの会話（spec/02 3.4） | 会話画面に移らず、少し暗くしたゲーム画面に重ねて出す。判定から約1.5秒、平坦の波形と音を見せてから会話を出し、「ピー」は会話の開始から3秒で消える（H3 の推奨案） |
| 病巣の見た目（P76） | 手順の段階ごとに見た目が変わる。例：ステージ1の「皮膚の中の異物」は、消毒前 → 切開 → 異物が見える → 摘出後の傷 → 縫い目 → テープ、と変わる。試作では画像の代わりに図形で描く |
| 追加した音 | 病巣の発生、評価ごとの音（OK／Cool／Good／Fine／Bad）、テーピング、トレイに置く、コンティニューポイント、ランク表示、ブリーフィングとゲームオーバーの BGM |
| H 章の推奨案 | H1（全スキップでゲーム中の会話も飛ばし、選択肢だけ出す）、H3、H4（トレーニングは会話なしで戻る）、H5、H6（減点は重ねる）、H7、H8、H9、H10、H11、H12（一時停止で血溜まりの自然増なども止まる）、H13、H14、H16、H17、H18、H19（開始位置の名前） |

## ステージ

| ステージ | 内容 | 確かめる仕様 |
|---|---|---|
| ステージ1 | scenario.md の会話。切り傷2つ → 破片 →（コンティニューポイント「裂傷の治療から」）→ 裂傷と重なった血溜まり2つ → 回復剤を30 → 皮膚の中の異物（消毒は省略可・切開・摘出・縫合・ゼリーは省略可・テーピング） | ヒールゼリーの8割判定、トレイ、血溜まりの同時吸引と重なりの無効、省略、バッドテーピング、段階ごとの見た目 |
| ステージ2（仮） | 患者A（裂傷）→（コンティニューポイント「2人目の患者から」）→ 止める会話・患者Bに差し替え → 麻酔を40（この患者は限度量 120）→ 腫瘍と膿 | 患者の差し替え、麻酔中の心電図、限度量の超過で平坦、円形の切開 |
| ステージ3（仮） | ゲーム前の選択肢で処置内容が変わる（腫瘍2つ／腫瘍と感染巣） | 処置内容の分岐、特定の病巣用の薬（抗菌剤） |
| ステージ4（仮） | 時間差で出血が増える。途中の止める会話の選択肢で闇落ち／光落ちが開放される | 時間差の出現、ゲーム中の選択肢 |
| 闇落ち／光落ち（仮） | クリアでエンディングの会話 | エンディング |
| トレーニング | クリアしたステージに出た病巣を1つずつ練習（指定／ランダム5つ）。難易度の切り替えを常に表示、制限時間なし | トレーニングモード、ベスト記録 |

## 構成

| パス | 内容 |
|---|---|
| `src/core.js` | 画面の拡大縮小と入力（範囲外のタッチは無視、中断は「離した」扱い）、音（Web Audio）、画像の先読み、セーブ、描画の部品 |
| `src/geometry.js` | マス座標の計算（距離は円で測る、ヒットエリアは円・線・マスの集まり） |
| `src/ecg.js` | 心電図（テンポ、波形、拍の音、平坦） |
| `src/lesion.js` | 病巣（種類＋配置、血溜まり・膿は独立した病巣）、病巣の点数（100点満点）と評価、ランク |
| `src/draw_lesion.js` | 病巣の見た目（段階ごとの look を図形で描く） |
| `src/surgery.js` | ゲーム画面（医療機器ごとの操作と判定、重なりの扱い、終了条件の優先順位、コンティニューポイント、止める会話・ゲームオーバーの会話、トレーニング） |
| `src/talk.js` | 会話の表示（会話画面と、ゲーム画面に重ねる会話の共通部品） |
| `src/screens.js` | タイトル（オプション）、ステージセレクト（フローチャート・難易度）、会話、開始位置、リザルト、ゲームオーバー、トレーニングの画面 |
| `src/main.js` | 起動、画面の切り替え、セーブとの橋渡し |
| `data/` | プログラム側：医療機器・病巣・システム（難易度・心電図）。内容側：ステージ・会話。値はすべて仮 |
| `assets/`、`tools/` | 仮素材と生成スクリプト（v03 からコピー）。試聴は `tools/sound_list.html` |

## 動作確認の方法（エージェント向け）

- ブラウザのプレビューが非表示だと画面の更新が止まるので、`app.step(秒)` を直接呼んで進める。入力は `app.input.events` に `{type:'down'|'move'|'up', x, y}`（論理座標）を積む。
- ファイルを変えたら、`fetch('src/….js', {cache:'reload'})` で読み直してから再読み込みする（古いスクリプトが使い回されるため）。
